# 2부 5장. 수익률 계산기

이 프로젝트는 분석 대상 단지를 등록하고 매수 시점과 보유 기간을 바꾸어 가며 실거래가 기반 수익률을 비교하는 예제입니다. 결과는 Google Sheets에 기록하거나, Google Sheets를 설정하지 않은 경우 콘솔에서 확인할 수 있습니다.

## 책과 프롬프트 대응

- 책: 『감을 확신으로 바꾸는 AI 부동산 투자』 2부 5장
- 프롬프트: [2부 5장 수익률 계산기 프롬프트](../../prompts/part02/chapter05/01_roi_calculator.md)

## 파일 구조

```text
part05_roi/
├── data/targets.json  # 예시 분석 대상 목록
├── main.py             # 수익률 계산 실행 진입점
├── calculator.py       # 실거래가 조회와 수익률 계산
├── targets.py          # 분석 대상 등록·삭제·조회
└── sheets.py           # Google Sheets 기록 또는 콘솔 출력
```

`data/targets.json`은 실습 흐름을 확인하기 위한 예시 파일입니다. 실제 분석에서는 자신의 비교 대상 단지와 전용면적에 맞게 목록을 등록하세요.

## 실행 전 준비

저장소 루트에서 의존성과 환경변수를 준비합니다.

```bash
uv sync
cp .env.example .env
```

계산에는 매매·전세 실거래가와 공동주택 정보가 필요합니다. 기준 매수 시점과 비교 시점에 해당하는 연도의 데이터가 DuckDB에 수집되어 있는지 먼저 확인하세요. 수집 범위 밖의 연도를 선택하면 일부 결과가 공란으로 나올 수 있습니다.

## 실행

```bash
uv run python -m projects.part05_roi.main
```

매수 기준월과 비교 기간은 `main.py`의 실행 설정에 따라 계산됩니다. 여러 시점과 기간을 비교할 때는 한 번에 하나의 기준만 고정하지 말고, 데이터가 실제로 존재하는 연도 조합을 사용하세요.

Google Sheets에 기록하려면 `.env`에 다음 값을 입력하고, 서비스 계정에 대상 시트 공유 권한을 부여하세요.

```dotenv
ROI_SHEET_ID=시트_ID
GOOGLE_SERVICE_ACCOUNT_KEY_PATH=서비스_계정_JSON_경로
```

## 계산 기준

- 기준월에 가장 가까운 유효 매매·전세 실거래가를 사용합니다.
- 매매 수익률은 매수 시점과 비교 시점의 가격 차이를 기준으로 계산합니다.
- 전세 실거래는 전세 계약만 사용합니다.
- 직거래와 취소된 매매 거래는 시세 왜곡을 줄이기 위해 제외합니다.
- 기본 계산은 세전 기준이며 세금, 중개보수, 대출이자와 같은 비용은 별도로 반영해야 합니다.

실거래가 기반 결과는 수집 시점과 신고·정정·취소 반영 상태에 따라 달라질 수 있습니다. 계산 결과를 확정적인 투자수익으로 해석하지 말고, 조건을 바꿔 비교하는 분석 자료로 사용하세요.
