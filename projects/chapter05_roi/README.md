# 5장. 매수 시점별 수익률 계산

[이 장의 프롬프트](../../prompts/part02/chapter05/) · [전체 실행 안내](../../README.md)

## 필요한 자료와 계산 기준

매매·전월세·공동주택 기본정보와 분석 대상 목록이 필요합니다. 목표월에 거래가 없으면 12개월 이내의 가장 가까운 거래를 찾습니다. 양쪽 월의 거리가 같으면 뒤의 월을 선택하므로 결과는 실제 과거 매수 가능 가격을 보장하지 않습니다. 초기 갭이 0 이하이거나 가격이 없으면 수익률을 비워둡니다.

## 실행

저장소 루트에서 실행합니다. 먼저 `.env`와 3장의 수집 자료를 준비하세요.

```bash
uv run python -m projects.chapter05_roi.main
```

목록은 `data/targets.json`에서 관리합니다. 포함된 목록은 예시이며, 자신의 DB에서 단지와 면적을 확인한 뒤 변경하세요. `targets.search()`, `add()`, `remove()`, `show()`로 검색·등록·삭제·조회를 할 수 있습니다. 같은 이름이 여러 지역에 있으면 `시군구` 인자를 지정합니다.

`ROI_SHEET_ID`와 `GOOGLE_SERVICE_ACCOUNT_KEY_PATH`를 설정하면 구글 시트에 기록합니다. 시트 기록 없이 확인하려면 `ROI_SHEET_ID`를 설정하지 않거나 빈 값으로 두세요.

## 확인할 것

조회 지역·기간·면적과 거래 건수가 의도한 조건인지 확인하세요. 데이터가 없거나 거래 건수가 적은 경우와 실제 값이 0인 경우를 구분합니다. 화면의 수치는 투자 성과나 미래 가격을 보장하지 않습니다.
