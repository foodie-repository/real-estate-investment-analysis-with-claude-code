## 필요한 자료와 계산 기준

매매·전월세 자료가 필요합니다. 주소·단지·평형을 맞춰 중앙값과 거래 건수, 갭·전세가율·고점 대비 비율을 계산합니다. 공동주택 기본정보가 없으면 세대수를 비워둘 수 있습니다. 비교표와 산점도·상자그림의 선택을 9장으로 전달할 수 있습니다.

## 실행

저장소 루트에서 실행합니다. 먼저 `.env`와 3장의 수집 자료를 준비하세요.

```bash
uv run streamlit run projects/chapter07_price_gap_table/dashboard/app.py
```

`GAP_DB_PATH`가 비어 있거나 없으면 기본 `data/apt_investment.duckdb`를 읽습니다. 다른 DB를 사용하려면 해당 파일 경로를 설정합니다. 지정한 DB에 필요한 자료가 없으면 수집 상태와 컬럼을 확인하세요.

## 7장과 9장 연결

두 앱을 같은 DB로 서로 다른 포트에 실행합니다. 예를 들어 7장에는 `--server.port 8527`, 9장에는 `--server.port 8529`를 붙입니다. 7장의 「가격·거래량 대시보드 연결」에 `http://localhost:8529`를 입력하고 표나 차트에서 대상을 선택합니다. `PRICE_VOLUME_URL`로 이 주소를 미리 설정할 수도 있습니다. 9장 앱은 별도로 실행해야 합니다.

## 확인할 것

조회 지역·기간·면적과 거래 건수가 의도한 조건인지 확인하세요. 데이터가 없거나 거래 건수가 적은 경우와 실제 값이 0인 경우를 구분합니다. 화면의 수치는 투자 성과나 미래 가격을 보장하지 않습니다.
