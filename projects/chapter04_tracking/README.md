# 4장. 관심단지 시세 트래킹

[이 장의 프롬프트](../../prompts/part02/chapter04/) · [전체 실행 안내](../../README.md)

## 필요한 자료와 계산 기준

매매·전월세·공동주택 기본정보와 관심단지 목록이 필요합니다. 단지명·전용면적뿐 아니라 전체 지역이 일치하는 거래를 조회합니다. 현재 참고 코드는 4.4절 후속 개선에 해당하는 동일 기준월의 중개 매매·신규 전세 중앙값과 거래 건수를 사용합니다. 갱신 전세는 따로 표시합니다.

## 실행

저장소 루트에서 실행합니다. 먼저 `.env`와 3장의 수집 자료를 준비하세요.

```bash
uv run python -m projects.chapter04_tracking.main
```

목록은 `data/watchlist.json`에서 관리합니다. 포함된 목록은 예시이며, 자신의 DB에서 단지와 면적을 확인한 뒤 변경하세요. `watchlist.search()`, `add()`, `remove()`, `show()`로 검색·등록·삭제·조회를 할 수 있습니다. 같은 이름이 여러 지역에 있으면 `시군구` 인자를 지정합니다.

`GOOGLE_SHEET_ID`와 `GOOGLE_SERVICE_ACCOUNT_KEY_PATH`를 설정하면 구글 시트에 기록합니다. 시트 기록 없이 확인하려면 `GOOGLE_SHEET_ID`를 설정하지 않거나 빈 값으로 두세요.

## 확인할 것

조회 지역·기간·면적과 거래 건수가 의도한 조건인지 확인하세요. 데이터가 없거나 거래 건수가 적은 경우와 실제 값이 0인 경우를 구분합니다. 화면의 수치는 투자 성과나 미래 가격을 보장하지 않습니다.
