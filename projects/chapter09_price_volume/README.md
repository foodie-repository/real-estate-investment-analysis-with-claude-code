# 9장. 가격·거래량 대시보드

[이 장의 프롬프트](../../prompts/part02/chapter09/) · [전체 실행 안내](../../README.md)

## 필요한 자료와 계산 기준

매매·전월세 자료가 필요합니다. 개별 거래 산점도와 월별 중위가·거래량을 제공합니다. 기본 매매 조회는 직거래와 취소 거래를 제외합니다. 7장에서 선택한 주소·단지·평형·면적 조건을 연결해 상세 조회할 수 있습니다. 출발 기간·층 조건은 설명에 표시하며, 9장의 조회 기간은 별도로 선택합니다. 층 제한은 적용하지 않고 전세에는 갱신 계약도 포함합니다.

## 실행

저장소 루트에서 실행합니다. 먼저 `.env`와 3장의 수집 자료를 준비하세요.

```bash
uv run streamlit run projects/chapter09_price_volume/dashboard/app.py
```

`PRICE_DB_PATH`가 비어 있거나 없으면 기본 `data/apt_investment.duckdb`를 읽습니다. 다른 DB를 사용하려면 해당 파일 경로를 설정합니다. 지정한 DB에 필요한 자료가 없으면 수집 상태와 컬럼을 확인하세요.

## 7장과 9장 연결

두 앱을 같은 DB로 서로 다른 포트에 실행합니다. 예를 들어 7장에는 `--server.port 8527`, 9장에는 `--server.port 8529`를 붙입니다. 7장의 「가격·거래량 대시보드 연결」에 `http://localhost:8529`를 입력하고 표나 차트에서 대상을 선택합니다. `PRICE_VOLUME_URL`로 이 주소를 미리 설정할 수도 있습니다. 9장 앱은 별도로 실행해야 합니다.

## 확인할 것

조회 지역·기간·면적과 거래 건수가 의도한 조건인지 확인하세요. 데이터가 없거나 거래 건수가 적은 경우와 실제 값이 0인 경우를 구분합니다. 화면의 수치는 투자 성과나 미래 가격을 보장하지 않습니다.
