# 『감을 확신으로 바꾸는 AI 부동산 투자』 미리보기

정상기 (푸디)의 책을 먼저 읽어볼 수 있는 정적 웹 미리보기입니다. `index.html`을 브라우저에서 열면 읽을 수 있습니다.

전체 목차와 저자 소개, 저자의 말, 이 책에 대하여, 이 책을 읽는 방법을 제공합니다. 본문 1~9장과 부록의 내용은 포함하지 않습니다.

- PC에서는 공간이 충분할 때 두 쪽을, 작은 화면에서는 한 쪽을 보여줍니다.
- 이전·다음 버튼, 좌우 방향키, 본문을 좌우로 미는 동작으로 넘길 수 있습니다.
- 위쪽의 글자 크기 버튼으로 본문을 조절할 수 있습니다. 장치와 글자 크기에 따라 페이지 수가 달라집니다.
- 그림 아래의 ‘그림 크게 보기’ 링크로 원본 이미지를 열 수 있습니다.
- 휴대전화에서는 왼쪽 위 목차 버튼으로 읽을 부분을 고릅니다.

2026-10-30 제작한 EPUB 샘플의 앞부속을 바탕으로 만든 미리보기입니다. 책의 문장과 그림을 보존하되 웹에서 읽기 편하게 조판했으므로 EPUB과 글꼴·줄바꿈·페이지 수가 다를 수 있습니다. 본문은 기기에 설치된 명조 계열 글꼴을 사용합니다.

책의 발췌문과 이미지는 저작자 표시를 유지한 열람용 샘플입니다. 저장소의 코드·실습 프롬프트 이용 조건을 책 원고 전체의 재사용 허락으로 해석하지 마세요. 재사용 범위는 저자에게 확인해 주세요. 제목용 Do Hyeon 글꼴의 SIL Open Font License는 `assets/OFL-DoHyeon.txt`에 포함되어 있습니다.
