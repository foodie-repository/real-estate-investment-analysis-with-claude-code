## 프롬프트와 코드의 관계

프롬프트는 도구를 처음 만들 때의 요구사항입니다. 완성 코드는 실행·검증 과정에서 보완한 참고 사례입니다. 특히 4장 완성 코드는 4.4절의 같은 기준월·정확한 면적·월별 중앙값 방식을 사용하므로 최초 전문의 최근 거래 한 건 방식과 구분합니다.

기존 공개 코드의 지역별 데이터 보존, 같은 이름의 다른 지역 단지 구분, 빈 DB 설정 처리, 자료가 없을 때의 안내와 연결 종료 처리를 유지했습니다. 내부 촬영용 화면은 독자용 코드에 추가하지 않았습니다. 데이터 재수집이나 실제 구글 시트 쓰기는 수행하지 않았습니다.

[이번 검증 범위](VALIDATION.md) · [프롬프트 전문과 PDF](../prompts/README.md)

4장 결과 화면은 원고에 반영된 여백 조정본으로 갱신했습니다. 7·8장 화면 파일명과 캡션도 개정본 번호로 맞췄습니다.
