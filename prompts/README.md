## 파일 사용 순서

1. 책의 해당 절에서 필요한 데이터와 준비 상태를 확인합니다.
2. 표에서 파일을 열고 전체 문안을 복사하거나, 파일을 실습 프로젝트 폴더에 저장합니다. 전문 파일에는 AI에게 전달할 문안만 들어 있습니다.
3. 클로드 코드 입력창에 붙여넣거나, `@`로 저장한 파일을 선택하고 책의 짧은 전달 요청을 함께 입력합니다.
4. AI가 확인한 자료와 조건을 읽고, 각 장의 실행·검증 절차에 따라 결과를 확인합니다.

여섯 파일은 서로 다른 도구를 만드는 요청입니다. 한꺼번에 전달하지 않습니다. 2·3장의 준비 요청, 짧은 비교 예시, 검증과 후속 수정 요청은 책에서 해당 단계에 사용합니다.

## 실습 중 확인할 차이

- 4장 문안은 최근 거래로 첫 버전을 만듭니다. 같은 기준월과 정확한 전용면적의 월별 중앙값·거래 건수로 개선하는 과정은 4.4절에서 이어집니다.
- 완성 코드의 실행 경로는 7장 `projects/chapter07_trade_map/`, 8장 `projects/chapter08_price_gap_table/`입니다. 두 폴더는 서로 다른 도구를 담고 있습니다.
- 부록 2는 9장의 `prompt_ch09_price_volume.md`를 출발점으로 삼아 새로운 대시보드의 요구사항을 정합니다. 원본 문안과 실습 중 만든 응용 문안은 별도 파일로 보관합니다.
