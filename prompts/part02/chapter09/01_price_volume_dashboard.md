## 2. 가격·거래량 대시보드 프롬프트 전체 문안

- 책 위치: 9.2 산점도와 월별 중위가 차트를 정하는 프롬프트

```text
**프로젝트: 아파트 가격·거래량 대시보드 만들기**

**먼저 할 일: 입력 데이터 확인**

현재 작업 폴더의 파일과 데이터 저장소를 살펴보고, 아래 자료를 이름이 아니라 내용과 출처로 식별한다. 실제 위치·형식·항목 대응·건수·기간·가격 단위를 표로 보고한 뒤 구현과 실행 검증까지 진행한다. 파일명이나 항목명을 추측하지 않는다. 필수 자료가 없거나 같은 역할의 후보가 여러 개이고 기존 설정으로도 구분할 수 없으면 후보와 확인할 내용을 먼저 알려준다.

**1. 목적과 구현 환경**

단지별 가격 수준과 상승·하락 정도를 거래량과 함께 비교하는 스트림릿 대시보드를 만든다. Python 3.11 이상, uv, DuckDB 읽기 전용 조회, Plotly를 사용한다. 기존 프로젝트의 실행 환경과 공통 설정을 활용하고 데이터 조회·전처리·차트·화면 조립은 역할별로 나눈다. 실행 진입점은 projects/chapter09_price_volume/dashboard/app.py로 한다. 전체 원자료를 Python 메모리로 가져오지 않고 지역·면적·기간 필터와 월별 집계는 가능한 한 SQL에서 처리한다.

**2. 입력 자료와 전처리**

- 아파트 매매 실거래와 임대차 실거래를 사용한다. 필요한 정보는 시도·시군구·읍면동, 단지명, 지번 또는 도로명, 전용면적, 계약 연월, 가격 또는 보증금, 층, 건축연도, 매매 거래 방식과 취소·해제 여부, 임대차의 전세·월세 구분이다. 공동주택 메타 정보나 좌표는 필요하지 않다.
- 실거래 후보는 기존 주택의 아파트 거래인지 확인한다. 비아파트 매매·임대차와 분양권·입주권 전매는 별도 자료이므로 필요한 컬럼이 같다는 이유로 후보에 섞지 않는다. 주택유형·거래대상 구분의 실제 값과 수집 자료의 역할을 확인하고, 아파트 전용 원본 테이블을 선택한다. 주택유형 컬럼이 없는 아파트 전용 자료는 계속 지원한다.
- DB에 원본 테이블과 이를 가공한 뷰가 함께 있으면, 실거래는 기본 테이블을 우선 확인하고 파생 뷰를 별도 원자료처럼 중복 선택하지 않는다. 현재 분석과 무관한 뷰가 없어진 외부 파일을 참조하더라도 전체 조회를 중단하지 않도록, 메타데이터로 후보를 먼저 좁히고 후보별 접근 오류를 구분한다. 같은 역할의 원본 후보가 실제로 여럿일 때만 자료 선택을 확인한다.
- 기존 공통 설정의 DB를 사용하되 PRICE_DB_PATH가 지정되어 있으면 그 DB를 우선한다. '전용면적(㎡)', '거래금액(만원)', '보증금(만원)'처럼 단위를 포함한 컬럼명과 일반 컬럼명을 확인하여 조회 경계에서 같은 의미로 맞춘다. 숫자에 쉼표가 있으면 제거하고 형을 변환한다. 원본 DB는 변경하지 않는다.
- 매매는 직거래를 기본 제외하고 거래 방식 NULL인 과거 행은 포함한다. 취소·해제일이 NULL 또는 'None', '-', 빈 문자열이면 미취소로 보고 나머지는 제외한다. '직거래 포함'을 선택해도 취소 거래는 포함하지 않는다.
- 임대차는 저장된 전세·월세 구분이 정확히 '전세'인 행만 쓴다. 월세액으로 저장된 구분을 임의 재분류하지 않는다. 구분 컬럼이 없으면 앞 장의 수집 결과부터 확인하도록 안내한다.
- 주소가 한 문자열이면 시도·시군구·읍면동으로 분리한다. '성남시 분당구'처럼 일반구가 있는 시군구를 보존하고 세종특별자치시의 시군구는 '세종시'로 처리한다. 지역과 단지를 이름만으로 연결하지 않는다.
- 추정평형은 floor(전용면적 × 0.4)다. '10평 미만, 10평대, 20평대, 30평대, 40평대, 50평대, 60평 이상' 7개 구간을 사용한다.
- 가격은 억 원으로 표시한다. 만원 단위라면 10000으로 나눈다. 월별 중위가는 원래 금액으로 중위값을 계산한 뒤 억 원으로 환산하며 표시 전에 반올림하여 집계하지 않는다. 개별 산점도 가격과 요약 최고·최저 가격은 소수점 첫째 자리로 표시한다.

**3. 화면과 사이드바**

- 제목은 '🏠 아파트 가격·거래량 대시보드', 넓은 화면, 처음부터 열린 사이드바를 사용한다. 메인 상단 여백은 1rem으로 하고 Streamlit 상단 헤더를 숨겨 제목 위의 큰 빈 공간을 없앤다. 메인 상단에 '📊 개별 실거래가', '📈 월별 중위가' 두 탭을 둔다. 페이지 제목과 소제목은 Streamlit 기본 크기를 유지하고 임의로 축소하지 않는다.
- 사이드바 '필터' 아래 순서는 시도 → 시군구 → 읍면동 → 단지 → 평형대 → 전용면적 (㎡) → 거래유형 → 기간 (연도) → 직거래 포함이다.
- 시도·시군구·읍면동·단지는 모두 복수 선택이다. 기본은 서울특별시, 강남구이며 읍면동·단지는 미선택(현재 상위 지역 전체)이다. 기본 지역이 데이터에 없으면 사용 가능한 지역을 안내한다. 시도를 비우면 전체 전국을 조회하지 말고 시도 선택을 안내한다.
- 상위 지역을 바꾸면 하위 후보를 갱신한다. 기존 선택 중 유효한 항목은 유지하고 범위를 벗어난 것만 제거한다. 시군구 미선택은 선택 시도 전체, 읍면동 미선택은 선택 시군구 전체, 단지 미선택은 선택 지역 전체를 뜻한다.
- 시군구 선택값은 '강남구 (서울특별시)', 읍면동은 '대치동 (서울특별시 강남구)'처럼 상위 지역을 병기한다. 단지는 '은마 (대치동)', '리센츠 (잠실동)'처럼 괄호 안에 읍면동만 표시한다. 후보에 단지명·읍면동이 같은 항목이 있으면 그 항목에만 시군구를 추가하고, 그래도 겹치면 시도까지 표시한다. 드롭다운 목록과 선택된 태그 모두 적용하되 내부 식별은 전체 지역 정보를 유지한다. 단지 선택 후보는 시도·시군구·읍면동·단지명 조합당 한 항목으로 만들고, 같은 조합에 지번·도로명이 여러 개 있어도 선택 항목을 중복시키지 않는다. 선택한 단지의 모든 주소를 조회하되 월별 비교 계열은 아래 기준대로 주소별로 나눈다.
- 필터 라벨·선택값·드롭다운 목록의 실제 글자 크기는 13px, 드롭다운 줄 높이는 글자 크기의 1.4배, 항목 한 행 높이는 약 25.6px로 맞춘다. 가상 스크롤 목록은 실제 항목 간 거리까지 확인하며, 필요하면 목록 전체에 0.64 배율을 적용하고 내부 폰트는 13px/0.64로 보정한다. 긴 선택 태그는 잘리지 않고 줄바꿈되어야 한다.
- 평형대는 복수 선택이고 기본은 30평대다. 미선택 시 하나 이상 선택하라는 안내를 표시한다.
- 전용면적은 두 손잡이 범위 슬라이더, 단위 ㎡, 0.1㎡ 간격으로 둔다. 선택 지역·단지·평형대에 존재하는 매매·전세 면적의 최소값과 최대값으로 범위를 정하되 취소 거래는 제외한다. 하한은 소수점 첫째 자리에서 내림, 상한은 올림하여 실제 면적을 누락하지 않는다. 평형대를 바꾸면 해당 범위 전체로 초기화한다. 지역·단지 변경 시 좁힌 범위가 새 범위와 겹치면 유지·보정하고 겹치지 않으면 새 전체 범위로 되돌린다. 면적이 하나이거나 자료가 없어도 오류가 나지 않아야 한다. 비연속 평형대를 골라도 그 사이의 미선택 평형대가 들어오지 않게 평형대와 면적 조건을 함께 적용한다.
- 거래유형은 '매매+전세', '매매만', '전세만' 라디오이며 기본은 매매+전세다. 기간은 데이터에 있는 시작 연도~종료 연도 범위 슬라이더이고 기본은 전체 기간이다. 직거래 포함 체크박스는 기본 해제한다.
- 두 탭과 매매 요약에는 같은 지역·단지·평형대·전용면적·거래유형·연도·거래 상태 조건을 적용한다. 차트의 X·Y축 확대는 화면 표시만 조절하며 사이드바 조회 조건이나 아래 요약을 바꾸지 않는다.

**4. 공통 차트 배치**

- 매매 가격 → 전세 가격 → 매매 거래량 → 전세 거래량 순서로 4행을 배치한다. 매매만 또는 전세만이면 해당 가격과 거래량 2행으로 표시한다. 가격 행과 거래량 행을 이중축으로 겹치지 않는다. 네 행은 같은 X축 범위를 공유하되 날짜 눈금은 맨 아래에만 두지 않고 각 행 아래에 모두 표시한다. 날짜는 YYYY-MM, 글자 크기는 10px이며 수평으로 표시한다. 표시 기간이 12개월 이하면 매월, 36개월 이하면 3개월, 84개월 이하면 6개월, 240개월 이하면 12개월, 그보다 길면 24개월 간격으로 표시한다. X축 범위를 좁히면 눈금 간격도 다시 조절한다. 네 행의 눈금 시점은 같아야 하며 다음 행 제목과 겹치지 않게 한다. 이 규칙은 두 탭 모두에 적용한다.
- 차트는 Plotly로 표시하며 범례·툴팁·축 조작이 실제 브라우저에서 동작하게 한다. 숨겨진 탭을 처음 열거나 창 너비를 바꿔도 차트 크기와 레이블이 맞아야 한다. 차트 높이는 800px, 가격과 거래량의 행 높이 비율은 각각 0.35·0.35·0.15·0.15다. 각 행에 연한 회색 테두리와 안쪽 상단 제목을 표시한다. 거래량 축의 눈금 간격은 1 이상의 정수이며 소수점 눈금을 만들지 않는다.

**5. 개별 실거래가 탭**

- 가격은 개별 거래의 산점도, 거래량은 같은 단지·주소·평형대별 월별 건수의 누적 막대다. 단지를 고르지 않은 전체 지역 조회에서는 평형대별로 구분한다. 같은 월의 점이 겹치지 않게 월 중순을 중심으로 소폭 수평 분산하되 원래 계약 연월은 툴팁에 유지한다. 같은 입력의 모양을 유지하도록 난수 시드는 42, 분산 범위는 월 15일 기준 ±12일로 한다. 같은 달의 조회 순서가 달라져도 같은 거래의 점 위치는 유지한다. 축 조절만으로 점이 좌우로 이동해서는 안 된다. 개별 거래 차트의 행 사이 여백 비율은 0.10이다.
- 단지를 선택하면 단지·주소·평형대별로 다른 색을 사용한다. 같은 대상은 두 탭과 매매·전세의 가격·거래량에서 같은 색을 쓴다. Plotly 기본 정성 팔레트와 Dark24 팔레트를 차례로 사용한다. 단지 미선택 조회의 평형대 색상은 10평 미만 #9E9E9E, 10평대 #FF9800, 20평대 #4CAF50, 30평대 #2196F3, 40평대 #9C27B0, 50평대 #F44336, 60평 이상 #795548이다. 점 크기는 4, 불투명도는 0.6, 거래량 막대 불투명도는 0.65다.
- 툴팁에는 단지명·평형대·계약 연월·가격·전용면적·추정평형·층을 표시한다. 흰 배경과 진한 글자로 읽기 쉽게 하고 대상의 색상 점을 함께 표시한다. 범례는 비교 대상별로 한 번만 표시하며 누르면 해당 대상의 가격과 거래량을 함께 숨기거나 표시한다.

**6. 월별 중위가 탭: 단지 비교와 기준월**

- 단지를 선택했으면 월·거래유형·단지·전체 주소·평형대별로 중위가와 거래량을 따로 집계한다. 전체 주소는 시도·시군구·읍면동과 지번을 우선 사용하고 지번이 없으면 도로명을 쓴다. 여러 단지를 하나의 중위선으로 합치지 않는다. 같은 이름의 다른 주소, 같은 단지의 다른 평형대도 구분한다.
- 단지를 하나도 선택하지 않았으면 선택 지역 전체를 합친 월별 중위가와 거래량을 표시하고, 단지를 선택하면 단지별 비교가 된다는 안내를 둔다.
- 비교 대상마다 다른 색을 쓰되 같은 대상의 매매·전세·가격선·거래량 막대는 같은 색으로 연결한다. 개별 실거래가 탭과 동일한 비교 대상 순서와 색상표를 사용하고 범례는 차트 위에 가로로 배치한다. 대상별 거래량 막대는 같은 월에 누적해 쌓는다. 거래량 Y축의 초기 상한에는 해당 월의 누적 합계가 모두 들어가도록 한다. 범례를 누르면 해당 대상의 가격과 거래량이 함께 숨겨지거나 나타난다.
- 두 탭의 범례와 툴팁의 대상 이름은 '은마 · 30평대'처럼 단지명·평형대를 표시한다. 같은 단지명이 서로 다른 주소에 있으면 읍면동을 붙이고 그래도 이름이 겹치는 대상만 전체 주소로 구분한다. 내부 식별에는 전체 주소를 유지한다. 가격 툴팁의 날짜는 YYYY-MM, 중위가는 소수점 둘째 자리와 억 단위다. 두 탭의 거래량 막대 툴팁에는 계약 연월, 대상 이름과 그 대상의 정수 거래 건수만 표시한다. 다른 대상의 건수나 표시 대상 월 합계 같은 별도의 합계 설명을 중복해서 넣지 않는다. 거래량 툴팁도 흰 배경 #FFFFFF, 회색 테두리 #D1D5DB, 진한 글자 #31333F로 통일하고 대상 색상은 작은 점이나 사각형에만 적용한다. 개별 실거래가 탭은 가리킨 막대 구간의 값만, 월별 중위가 탭은 같은 월의 대상별 값을 함께 보여준다.
- 월별 중위가 탭의 차트 위에서 '표시 방식'을 '가격 (억 원)'과 '기준 시점 100' 가로 라디오로 선택한다. 기본은 가격이다. 기준 시점 100에서는 각 대상·거래유형의 해당 월 중위가 / 공통 기준월 중위가 × 100으로 계산하고 기준월부터 표시한다. 지수·변화율도 소수점 둘째 자리로 표시하며 변화율은 지수-100이다. 가격 행에 100 기준 점선을 추가한다.
- 기준월 조작부는 '기준 시점 100'일 때만 표시 방식 오른쪽에 배치한다. 가격 모드에서는 기준월 슬라이더와 버튼을 숨긴다. 폭 비율은 표시 방식 1, 기준월 2다. 기준월은 월 단위 슬라이더와 양쪽 ◀·▶ 버튼으로 조절하고 버튼은 약 28×28px로 작게 만든다. 버튼은 달력상 한 달씩 이동하며 양 끝에서는 비활성화한다. 드롭다운으로 대신하지 않는다.
- 기준월 후보는 조회 결과의 첫 월~마지막 월 사이 모든 달이며 거래 없는 달도 포함한다. 기본 기준월은 표시할 모든 대상·평형대·거래유형에 유효한 양수 중위가가 있는 첫 공통월이다. 공통월이 없으면 첫 관측월로 시작하고 조건을 좁히거나 기준월을 바꾸라는 안내를 표시한다.
- 기준월 가격이 없거나 유효하지 않은 대상·거래유형만 제외하고 무엇이 제외됐는지 경고한다. 각 대상의 첫 거래월을 제각각 기준으로 사용하거나 가격을 보간해 기준값을 만들지 않는다. 기간 전체에 거래가 없는 선택 단지도 별도로 알린다. 비교 가능한 대상이 없으면 빈 차트 대신 기준월 선택 안내를 표시한다.
- 관측이 있는 달은 실선과 점으로 표시한다. 중간에 거래 없는 달은 가격을 결측으로 남기고, 그 양쪽의 실제 관측점만 같은 색 점선으로 연결한다. 점선에는 가격 툴팁을 만들지 않고 앞뒤 끝 구간을 연장하지 않는다. 거래 없는 달의 거래량은 0건이다. '점선은 실제 가격 관측이 없는 기간의 참고 연결선'이며 거래 건수와 면적·층 구성이 중위가에 영향을 줄 수 있음을 설명한다.

**7. 두 탭의 축 범위 조절**

- 개별 실거래가 탭과 월별 중위가 탭의 두 표시 방식 모두 맨 아래 거래량 행 아래에 공통 X축 범위 슬라이더 하나를 배치한다. 기준월과 X축은 Streamlit의 월 단위 선택 슬라이더를 사용하고, 세로 Y축은 필요한 경우 자체 컴포넌트로 구현한다. 월 단위 두 손잡이이며 네 행을 함께 확대한다. 월별 중위가는 첫·마지막 월의 막대가 잘리지 않도록 양 끝 약 15일 여유를 둔다. 개별 실거래가는 선택한 시작월 1일부터 종료월 다음 달 1일까지 표시하고 거래량 막대는 월 중앙에 배치하여, 선택한 달의 모든 점과 막대가 들어가도록 한다.
- 각 차트 행 왼쪽에는 별도의 두 손잡이 Y축 세로 슬라이더를 둔다. 매매+전세이면 4개, 단일 거래유형이면 2개다. 한 행을 조절해도 다른 행의 Y축은 유지한다. 가격·지수는 0.01, 거래량은 1 단위로 조절한다.
- 차트의 X·Y축 슬라이더에 모두 회색 계열을 적용한다. X축은 기본 빨간색이 남지 않도록 선택 구간·손잡이·값 표시까지 회색으로 처리하고, 기준월과 사이드바 슬라이더에는 기본 테마를 유지한다. 손잡이 #b8b8b8, 세로 선택 구간 #b8b8b8, 나머지 세로 레일 #e2e4e7의 회색 계열을 사용한다. 세로 슬라이더 영역 폭은 48px, 차트와의 간격은 4px다. 각 레일 위·아래 끝을 해당 차트의 실제 그리기 영역에 맞춘다. 제목·눈금과 손잡이 숫자가 겹치지 않도록 두 탭 모두 차트 행 사이 여백 비율은 0.10, 차트 여백은 좌우 50px·상단 60px·하단 50px로 한다. 여러 iframe으로 구현할 경우 기본 줄 간격 때문에 두 번째 이후 레일이 밀리지 않도록 한다.
- 기본 Y축은 유효한 값에 약 5% 여유를 주되 거래량 하한은 0, 지수 범위에는 100을 포함한다. 축 확대는 개별 거래 가격·점 위치·중위가·거래량·기준월 환산값을 다시 계산하지 않는다. 두 탭의 축 선택 상태는 서로 독립적으로 유지한다. 한 탭에서 범위를 좁힌 뒤 다른 탭을 열어도 그 탭의 범위는 바뀌지 않고, 원래 탭으로 돌아오면 조절한 범위가 남아 있어야 한다. 기준월을 바꾸면 환산값을 다시 계산하고 필요한 축 범위를 갱신한다. 데이터가 한 달뿐이거나 값이 일정해도 오류가 나지 않아야 한다.

**8. 가격·갭 대시보드에서 선택한 대상 받기**

- 앞 장의 가격·갭 대시보드와 프로젝트 안내를 먼저 확인하고, 그 대시보드가 만든 공통 연결 모듈과 주소·단지명 정리 기준을 그대로 재사용한다. 임의로 다른 URL 형식이나 단지 식별 기준을 만들지 않는다. 필요한 공통 기능이 없다면 두 앱이 같은 규칙을 사용하도록 함께 보완하되 기존 표·차트·계산 기준은 유지한다. 7장 앱이 없으면 이 장의 직접 조회 기능은 완성하고 연결 검증만 준비되지 않았다고 알린다.
- URL에 연결 정보가 없으면 앞서 지정한 ‘필터’ 사이드바와 직접 조회를 사용한다. 연결 정보가 있으면 ‘연결된 비교 대상’ 사이드바를 표시하고 ‘연결 해제 · 직접 조회’, ‘단지·평형대’, ‘전용면적 (㎡)’, ‘거래유형’, ‘기간 (연도)’, ‘직거래 포함’ 순서로 배치한다. 링크로 받은 대상을 처음에 모두 선택한다.
- 조회 대상은 시도·시군구·읍면동·정리한 단지명·정리한 전체 주소·평형대를 묶은 목록으로 적용한다. 각 묶음을 정확히 일치시켜, 같은 이름의 다른 주소나 선택하지 않은 평형대가 끼어들지 않게 한다. A단지 20평대와 B단지 30평대는 두 조합만 조회한다. 이 대상 구분을 개별 거래·월별 중위가·거래량·요약에 똑같이 적용한다.
- 목록과 선택 태그는 ‘라이프 · 30평대 (독산동)’처럼 단지명·평형대·읍면동만 표시한다. 단지명·평형대·읍면동이 같은 후보가 서로 다른 시군구에 있으면 시군구를 추가하고, 시군구까지 같으면 시도를 추가한다. 번지와 도로명주소는 표시하지 않되 내부 식별 정보에서 삭제하지 않는다. 기존 사이드바의 13px 글자와 좁은 드롭다운 간격을 유지한다.
- 연결된 대상 중 일부를 제외하거나 다시 선택할 수 있다. 모두 해제하면 대상을 선택하라는 안내를 표시하고 전체 지역으로 조회를 확대하지 않는다. 연결 해제를 누르면 URL의 연결 정보를 지우고 기존 직접 조회 화면으로 돌아간다.
- 전용면적은 출발 화면에서 전달한 범위를 그대로 적용한다. 대상별 평형대와 면적 조건을 함께 적용하며 좁힌 범위를 자동으로 넓히지 않는다. 전달한 면적 범위가 없을 때만 해당 대상의 전체 면적 범위를 기본으로 사용한다. 이후 사용자가 범위를 조정할 수 있게 한다.
- 기간 기본값은 선택 대상의 DB에서 확인되는 전체 거래 이력을 포함하는 시작·종료 연도다. 출발 화면의 최근 비교 기간으로 제한하지 않는다. 전세는 신규·갱신을 모두 포함하고 출발 화면의 층 제한은 적용하지 않는다. 직거래 기본 제외와 취소 거래 제외는 이 장의 기준을 따른다. 출발 기간·층 조건, 현재 조회 기간과 전세 포함 기준의 차이를 메인 화면에 짧게 안내한다. 월별 중위가와 출발 비교 기간 전체 중앙값이 다를 수 있다는 점도 알린다.
- 연결 정보는 새 URL로 처음 들어왔을 때만 초기 조건으로 적용한다. 같은 화면에서 사용자가 바꾼 대상·기간·면적·거래유형은 차트 조작과 재실행 때 유지한다. 원래 링크를 새 탭으로 열거나 새로고침하면 전달받은 대상·면적과 기본 장기 기간으로 복원한다.
- 필수 정보가 없거나 형식·버전·범위가 잘못됐거나 10개를 초과한 연결은 오류를 안내하고 ‘연결 정보 지우기’를 제공한다. 잘못된 링크를 조용히 무시하고 기본 지역으로 조회하지 않는다. 같은 대상의 중복 전달은 하나로 처리한다.
- 선택 대상의 거래가 없거나 해당 기간·면적에서 일부 대상만 조회되지 않으면 어느 대상인지 안내한다. 다른 주소를 대신 선택하거나 모든 지역으로 넓히지 않는다. 서로 다른 DB를 사용한 경우 수집 범위를 확인하도록 안내한다.
- 두 앱을 같은 DB로 각각 실행하고 실제 접속 주소를 알려준다. 7장의 사이드바 주소 입력 또는 PRICE_VOLUME_URL로 9장 주소를 설정하는 방법도 안내한다. 특정 포트·저자 경로를 하드코딩하지 않으며 9장 서버를 링크 클릭만으로 자동 실행하지 않는다.

**9. 매매 요약과 실행 검증**

차트 아래에 같은 사이드바 조건의 매매 총 거래 건수, 기간 내 최고가·최저가, 최근 거래 최대 3건(계약 연월·단지명·전용면적·가격·층)을 표시한다. 최근 거래는 계약 연월 내림차순, 같은 월에서는 거래금액 내림차순으로 선택한다. 전세만 선택하면 매매 요약 수치를 표시하지 않는다.

구현만 설명하지 말고 앱을 직접 실행한다. 사용 자료·계산 샘플·실행 명령·접속 주소와 다음 검증 결과를 보고한다. 자료가 없어 확인할 수 없는 항목은 구분한다.
- 데이터에 존재하는 서로 다른 시군구의 단지 두 개를 복수 선택하여 두 탭과 요약에 같은 필터가 적용되고, 두 탭에서 단지·평형대별 가격과 누적 거래량이 같은 색으로 구분되는지 확인한다. 단지 한 개·여러 평형대, 단지 여러 개·한 평형대, 단지 여러 개·여러 평형대를 각각 시험한다. 같은 월의 누적 건수가 원자료 합계와 같고 상한에 잘리지 않는지, 범례를 누르면 해당 가격과 거래량만 함께 숨겨지고 다시 나타나는지 확인한다.
- 평형대 변경 시 면적 범위가 연동되고 면적을 좁히면 실제 거래와 집계·요약이 함께 달라지는지 원자료로 대조한다.
- 공통 기준월의 지수가 100인지, 기준월이 없는 대상만 제외되는지, 이전·다음 달 버튼이 한 달씩 이동하는지 확인한다. 거래 없는 달을 점선으로 표현하되 실제 가격을 생성하지 않았는지 확인한다.

- 두 탭에서 공통 X축과 각 Y축을 실제로 조작하여 다른 축과 원래 값·점 위치가 유지되는지 확인한다. 탭을 왕복해 각각의 축 범위가 유지되는지, 개별 실거래가의 첫·마지막 선택 월이 잘리지 않는지도 확인한다. 회색 슬라이더와 간격·정렬·정수 거래량 눈금·툴팁·단지 표시가 요구사항에 맞는지 확인한다. 산점도와 두 탭의 거래량 막대에 실제로 마우스를 올려 흰 툴팁·진한 글자·대상 색상 표식과 합계 설명이 없는 것을 확인한다.
```
