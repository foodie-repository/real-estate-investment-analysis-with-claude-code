### 먼저 할 일: 입력 데이터 확인
현재 작업 폴더의 파일과 데이터 저장소를 살펴보고, 아래 자료를 이름이 아니라 내용과 출처로 식별한다. 실제 위치·형식·항목 대응·건수·기간·지역 수준을 표로 보고한 뒤 구현과 실행 검증까지 진행한다. 파일명이나 항목명을 추측하지 않는다. 필수 자료가 없거나 같은 역할의 후보가 여러 개이고 기존 설정으로도 구분할 수 없으면 후보와 확인할 내용을 먼저 알려준다.

### 1. 목적과 구현 환경
KB 아파트 지표를 시군구 경계 지도와 지역별 시계열로 비교하는 스트림릿 대시보드를 만든다. Python 3.11 이상, uv, DuckDB 읽기 전용 조회, Plotly 선 그래프, Folium과 streamlit-folium 지도를 사용한다. 기존 프로젝트의 실행 환경과 공통 설정을 활용하고, 데이터 조회·전처리·지도·차트·화면 조립은 역할별로 나눈다. 실행 진입점은 projects/part06_kb_dashboard/dashboard/app.py로 한다. 전체 원자료를 Python 메모리로 가져오지 않고 지역·지표·기간 필터와 집계는 가능한 한 SQL에서 처리한다.

### 2. 입력 자료와 데이터 연결
- 필수 자료는 KB의 아파트 매매가격지수·전세가격지수·전세가율, 지역·계약 시점·거래 방식·취소 여부가 있는 아파트 매매 실거래, 시군구 행정경계 GeoJSON이다. 아파트·월간 자료를 사용하고 다른 주택 유형이나 주간 자료를 섞지 않는다. 사용 가능한 지역·기간·건수와 화면의 자료 범위 안내는 연결된 DB에서 구하며, 구현 시 확인한 예시 지역 목록이나 날짜를 코드에 고정하지 않는다.
- 실거래 후보는 기존 주택의 아파트 거래인지 확인한다. 비아파트 매매·임대차와 분양권·입주권 전매는 별도 자료이므로 필요한 컬럼이 같다는 이유로 후보에 섞지 않는다. 주택유형·거래대상 구분의 실제 값과 수집 자료의 역할을 확인하고, 아파트 전용 원본 테이블을 선택한다. 주택유형 컬럼이 없는 아파트 전용 자료는 계속 지원한다.
- DB에 원본 테이블과 이를 가공한 뷰가 함께 있으면, 실거래와 원본 지수는 기본 테이블을 우선 확인하고 파생 뷰를 별도 원자료처럼 중복 선택하지 않는다. 필요한 선택 자료인 전년동월대비 뷰는 따로 확인한다. 현재 분석과 무관한 뷰가 없어진 외부 파일을 참조하더라도 전체 조회를 중단하지 않도록, 메타데이터로 후보를 먼저 좁히고 후보별 접근 오류를 구분한다. 같은 역할의 원본 후보가 실제로 여럿일 때만 자료 선택을 확인한다.
- 기존 공통 설정의 기본 DB를 사용하되 KB_DB_PATH가 지정되어 있으면 그 DB를 우선한다. DB와 GeoJSON을 수정하지 않는다. 경계의 좌표계와 지역코드·지역명 속성을 확인하고 지도 좌표계에 맞춘다. 매매 자료는 시도·시군구·읍면동이 별도 컬럼인 형식과 시군구 컬럼에 전체 주소가 들어 있는 형식을 모두 지원한다. 주택유형 컬럼이 있으면 아파트로 거르고, 그 컬럼이 없는 아파트 전용 테이블도 사용할 수 있게 한다. 실제 존재하는 컬럼을 확인해 조회식을 선택하고 특정 DB에만 있는 컬럼을 필수로 가정하지 않는다.
- 다른 기관의 가격지수나 주간 자료가 함께 있어도 KB 월간 아파트 자료만 이 대시보드의 지수 후보로 삼는다.
- 시도 수준 값은 KB가 제공하는 시도 자료를 사용한다. 시군구 값을 단순 평균하여 시도 값으로 대체하지 않는다. 지역코드는 문자열로 유지하고 시도와 시군구 수준을 구분한다.
- 전년동월대비 증감률 자료와 전월 대비 증감률 자료가 추가로 있으면 출처·지역 수준·기간을 확인한다. 이 두 자료는 선택 사항이다. 없다는 이유로 구현을 중단하지 않는다.

### 3. 지표 계산과 결측 처리
- 전년동월대비 증감률(%) = (당월 가격지수 / 전년 같은 달 가격지수 - 1) × 100이다. 행 순서상 12번째 전 값이 아니라 정확히 12개월 전 값을 연결한다. 지도와 시계열 모두 검증된 기존 전년동월대비 자료가 있으면 활용하고, 없으면 해당 월의 원본 지수와 전년 같은 달 원본 지수로 계산한다. 기존 자료가 있는 과거 월을 최근 원본 지수의 기간으로 잘라내지 않는다. 0 이하이거나 유효하지 않은 분모로 계산하지 않는다. 증감률과 전세가율은 소수점 첫째 자리까지 표시한다.
- 매매 거래량은 계약 연월·시군구별 건수다. 직거래를 제외하며 거래 방식이 NULL인 행도 지도 거래량에서 제외한다. 취소·해제일이 NULL 또는 'None', '-', 빈 문자열이면 미취소로 보고 나머지는 제외한다. 건수는 정수로 표시한다.
- 시군구 주소는 시도까지 포함해 연결하고, 일반구가 있는 도시와 세종특별자치시를 처리한다. 경계와 KB 자료는 지역코드를 우선 연결하며, 동명 시군구를 이름만으로 합치지 않는다. 매칭 누락을 보고한다. 화성시 신설 일반구(41591, 41593, 41595, 41597)에 개별 KB 값이 없고 기존 화성시(41590) 값이 있으면 상위 도시 값을 쓰되 해당 지역과 대체 사실을 지도 아래에 알린다. 다른 결측을 0으로 채우지 않는다.
- '시작 시점 100'은 선택한 시작월 가격지수를 100으로 환산한다. 표시값 = 해당 월 지수 / 시작월 지수 × 100이다. 100 기준선을 점선으로 표시하고, 120은 20% 상승·90은 10% 하락임을 설명한다. 시작월에 유효한 양수 지수가 없는 지역은 제외하고 지역명을 경고한다. 다른 달을 지역별 기준월로 대신 쓰지 않는다.
- 원본 지수가 최근 기간에만 있고 더 오래된 월별 전월 대비 증감률이 있다면, 가장 이른 유효 원본 지수에서 과거로 역산한다. 이전 달 지수 = 현재 달 지수 / (1 + 현재 달 전월 대비 증감률 / 100)이다. 지역별로 현재 달과 바로 전 달의 증감률 행이 연속되고 현재 달 증감률이 유효하며 -100%보다 클 때만 연결한다. 누락 월을 건너뛰거나 원본 지수를 덮어쓰지 않는다. 복원 구간과 증감률 반올림에 따른 차이 가능성을 화면에 안내한다. 증감률이 없다면 저장된 원본 지수 기간만 제공한다.

### 4. 화면 구성과 공통 스타일
- 페이지 제목은 'KB부동산 시각화 대시보드'로 하고 가로 폭을 넓게 사용한다. 메인 영역의 상단 여백은 1rem, 하단은 0으로 하고 Streamlit 상단 헤더는 숨긴다. 사이드바 '필터 설정' 아래 가로 라디오로 '지도 대시보드', '지도 상세', '시계열 분석'을 전환한다. 첫 화면은 지도 대시보드다. 가로 라디오는 사이드바 너비가 부족하면 줄바꿈한다. 페이지 제목은 Streamlit 기본 크기를 유지한다. 2×2 지도의 지표 제목은 20px·줄 높이 1.25로 간결하게 표시한다.
- 사이드바 필터 라벨·선택값·펼친 드롭다운 목록의 실제 글자 크기를 13px로 맞춘다. 드롭다운 줄 높이는 글자 크기의 1.4배, 항목 한 행 높이는 약 25.6px로 맞추고 긴 선택값은 잘리지 않게 줄바꿈한다. 가상 스크롤 목록은 글자만 줄여도 행 간격이 남을 수 있으므로 실제 항목 간 거리까지 확인한다. 필요하면 목록 전체에 0.64 배율을 적용하고 내부 폰트는 13px/0.64로 보정한다.
- 지도는 V-World 기본지도를 사용하고 .env의 VWORLD_API_KEY를 읽는다. 키가 없으면 설정 안내를 표시한다. 키 값을 화면이나 로그에 출력하지 않는다. 배경 타일의 불투명도는 0.3이고 V-World 출처를 표시한다.

### 5. 지도 대시보드와 지도 상세
- 두 지도 뷰의 시도 필터는 복수 선택이고 기본 선택은 '서울'만이다. 서울·경기 등 축약 이름을 표시하되 실제 지역 정보와 정확히 연결한다.
- 지도 연월 후보는 매매·전세 전년동월대비, 전세가율, 유효 매매 거래의 네 자료에 공통으로 존재하는 월의 교집합으로 정한다. 기존 전년동월대비 자료가 있으면 시군구 수준의 날짜가 존재하는 월을 사용하고, 없으면 원본 지수와 정확히 12개월 전 양수 지수가 연결되는 월을 사용한다. 전세가율도 시군구 수준의 날짜가 존재하는 월을 사용한다. 연월 후보를 만들 때 개별 지역의 결측값 때문에 그 월 자체를 삭제하지 말고, 해당 지역은 지도에서 결측으로 표시한다. 이 후보는 시계열의 조회 기간을 제한하지 않는다. 교집합이 없으면 자료의 기간을 확인하라는 안내를 표시한다. 연월의 기본값은 이 공통 월 중 가장 최근 월이다. ◀·▶ 버튼, 현재 연월 표시, 연월 슬라이더를 사이드바에 배치하고 서로 연동한다. 데이터가 없는 기간을 임의로 생성하지 않는다.
- 지도 대시보드는 2×2로 배치한다. 좌상 매매가격 전년동월대비 증감률, 우상 전세가격 전년동월대비 증감률, 좌하 전세가율, 우하 매매 거래량 순서다. 한눈에 비교하도록 브라우저 표시 영역 1753×871px 및 1440×900px, 배율 100%, 사이드바를 펼친 상태에서 제목과 네 지도 전체가 세로 스크롤 없이 들어오게 한다. 지도 높이는 고정 400px 대신 화면 높이에 맞춰 조절하며, 기본 계산은 (화면 높이-250px)/2, 최소 210px·최대 480px다. 지도 프레임뿐 아니라 내부 지도도 같은 높이로 갱신해 아래가 잘리지 않게 한다. 작은 모바일 화면에서는 스크롤을 허용한다. 각 지도에는 지표 제목, 시군구 경계, 겹치지 않는 지역명·값 라벨을 표시한다. 입력 조사 표와 지역 연결 안내를 지도 사이에 반복해 넣지 않고, 네 지도 아래 접힌 안내 한 곳으로 모은다.
- 네 지도 모두 파랑↔흰색↔빨강을 사용한다. 색상은 #2166ac, #4393c3, #92c5de, #d1e5f0, #f7f7f7, #fddbc7, #f4a582, #d6604d, #b2182b 순서다. 색상 범위는 선택 시도의 경계만 남기기 전에 해당 월의 전체 유효 시군구 값으로 정한다. 경계선은 #999999·0.5px, 채움 불투명도는 0.75, 결측은 #cccccc로 한다. 값이 있는 지역의 라벨만 13px·굵기 600·줄 높이 1.3으로 표시한다. 모든 라벨을 무조건 노출하지 않는다. 현재 화면의 실제 글자 영역을 비교해 최소 4px 간격을 두고, 겹칠 때는 색상 중심값과의 차이가 큰 지역부터 표시한다. 지도 밖으로 잘리는 라벨도 숨긴다. 확대·축소·이동·지역 변경·월 변경·창 크기 변경 후 다시 배치하고, 확대하면 공간이 생긴 지역의 라벨을 추가한다. 라벨을 숨겨도 해당 경계의 색과 값은 유지하며, 모든 지역에서 마우스를 올리면 전체 지역명과 지표 값·단위 또는 자료 없음을 확인할 수 있게 한다. 증감률은 0, 전세가율과 거래량은 조회한 유효 값의 중앙값을 색상 중심으로 삼고 중심 양쪽에 대칭 범위를 적용한다. 결측은 값이 있는 지역처럼 칠하지 않는다.
- 네 지도의 색상 범례는 각 지도 오른쪽에 폭 약 64px의 별도 영역을 확보해 세로로 표시한다. 지도 위에 겹쳐 넣지 않고 지표 제목을 범례에 반복하지 않는다. 위는 최대값, 중간은 중심값, 아래는 최소값을 표시하며 거래량은 정수다. 지도 아래 접힌 안내에서 회색은 자료 없음이며 0건이 아니라는 점과 라벨 표시 우선순위를 설명한다.
- 지도 상세에서는 사이드바에서 네 지표 중 하나를 선택하고 높이 850px의 큰 지도를 표시한다. 지표나 연월을 바꿀 때 사용자가 조절한 지도 중심·확대 배율을 유지한다. 2×2 지도도 연월 변경 시 각 지도의 확대 상태를 유지한다.

### 6. 시계열 분석
- 사이드바 순서는 지표, 비교 방식, 시도, 시군구다. 지표는 '매매가격', '전세가격', '전세가율'이고 거래량은 제외한다. 매매·전세가격에서만 '전년동월대비 증감률'과 '시작 시점 100' 라디오를 표시하며 기본은 전년동월대비다. 전세가율은 원래 비율을 표시한다.
- 시도는 복수 선택, 기본은 서울·경기다. 시군구는 복수 선택, 기본은 미선택이다. 시군구 미선택 시 선택한 시도들을 비교한다. 시군구 선택 시 해당 시군구들을 비교한다. 시도에 따라 시군구 후보를 좁히되 시도 미선택 시 전국 후보를 제공한다. 시도와 시군구가 모두 없으면 선택 안내를 표시한다. 동명 시군구는 '강서구 (서울특별시)'처럼 구분한다.
- 전년동월대비와 전세가율은 조회 가능한 전체 기간을 기본으로 표시한다. 지도에서 선택한 최근 월 때문에 시계열을 최근 기간으로 제한하지 않는다.
- '시작 시점 100'에서는 차트 위에 두 손잡이가 있는 월 단위 슬라이더 '비교 기간 · 시작월(기준값 100) ~ 종료월'을 배치한다. 왼쪽 손잡이는 기준월, 오른쪽은 종료월이다. 드롭다운 두 개로 대신하지 않는다. 기본 시작월은 선택한 모든 지역에 유효한 지수가 있는 첫 공통월, 종료월은 마지막 월이다. 서울·경기의 과거 자료가 연결되는 집필 데이터에서는 2003-06부터지만 이 날짜를 모든 DB에 강제하지 않는다. 더 이른 달도 선택할 수 있고 기준값이 없는 지역은 제외 사실을 알린다. 공통월이 없으면 첫 가용월로 시작하고 안내한다.
- 선 그래프는 지역별 한 선, 색상 구분, 오른쪽 세로 범례, 높이 500px로 표시한다. 차트는 st.plotly_chart로 표시한다. 차트 여백은 왼쪽 50px·오른쪽 120px·위 50px·아래 100px, 선 두께는 1.8px, 범례 글자는 11px, 배경은 흰색, X축 눈금은 6개월 간격이다. 툴팁은 같은 X축 시점의 지역 값을 함께 보여주는 방식이다. X축은 YYYY-MM, 툴팁은 YYYY-MM·지역·값이며 값은 소수점 첫째 자리다. 실제 결측 구간의 선을 연결하지 않는다.
- 모든 비교 방식에 X축과 Y축 범위 슬라이더를 제공한다. X축 슬라이더는 차트 바로 아래에 두고 기본은 전체 표시 기간이다. Y축은 차트 왼쪽에 두 손잡이 세로 슬라이더로 배치한다. 세로 슬라이더는 필요한 경우 이 장 폴더 안에 자체 컴포넌트로 구현하고 뒤 장의 파일에 의존하지 않는다. 두 축은 표시 범위만 바꾸며 지수 기준값이나 원자료를 다시 계산하지 않는다. 시작 시점 100에서도 차트 위 비교 기간 슬라이더와 차트 아래 X축 표시 범위 슬라이더는 별도로 둔다.
- 슬라이더는 회색 계열로 통일한다. 손잡이 #b8b8b8, 세로 선택 구간 #b8b8b8, 나머지 세로 레일 #e2e4e7를 사용한다. Y축 슬라이더 영역 폭은 48px, 차트 영역과 간격은 4px로 한다. 레일 양 끝은 실제 차트 그리기 영역의 위·아래에 맞추며 차트 제목·축 레이블 여백에 걸치지 않게 한다. 값의 유효 범위에 약 5% 여유를 두고 두 손잡이가 교차하지 않게 한다. X축은 한 달 단위, Y축은 0.01 단위로 조절한다. 한 달 또는 일정한 값만 있어도 오류 없이 표시한다.
- 차트 아래 히트맵 테이블은 Streamlit의 st.dataframe과 셀 배경색을 사용한다. 행=지역, 열=YYYY-MM, 값=현재 비교 방식의 값이다. X축 표시 기간과 연동하고, Y축 확대 때문에 테이블 값을 숨기지 않는다. 증감률은 0, 시작 시점 100은 100, 전세가율은 중앙값을 중심으로 파랑↔흰색↔빨강을 적용한다. 값은 소수점 첫째 자리, 실제 결측은 '-'로 남긴다. 선택해 표시하는 지역 수만큼만 행을 만들고 테이블 높이를 내용에 맞춰 빈 행이나 고정 높이의 빈 공간을 만들지 않는다(height="content"). 결측을 없애려 실제 날짜나 지역을 임의로 삭제하지 않는다.

### 7. 실행과 검증
구현만 설명하지 말고 앱을 직접 실행한다. 입력 자료와 계산 샘플, 실행 명령·접속 주소, 아래 확인 결과를 보고한다. 사용자가 확인할 실행 주소에는 기존 공통 설정의 DB를 연결한다. 별도 검증용 축소 데이터로 실행한 주소를 실제 데이터 화면처럼 안내하지 않는다. 각 주소의 데이터 지역·기간과 실행 코드 위치를 보고서에서 구분한다. 자료가 없어 확인할 수 없는 항목은 구분한다.
- 지도 대시보드를 1753×871px와 1440×900px에서 캡처하고 네 지도 하단이 화면 안에 있는지 확인한다. 서울 및 서울·경기 선택 상태에서 지도 라벨끼리 겹치지 않는지, 범례가 지도 바깥에 있는지, 지도 확대 후 라벨이 다시 배치되는지 검사한다.
- 매매 거래량은 선택 월의 시군구별 원자료 집계와 지도 연결 결과를 대조한다. 일부 지역만 수집된 DB와 실제 전체 DB를 구분하며 결측 지역을 임의로 0건으로 채우지 않는다. 연결 안내는 필요할 때 네 지도 아래 한 곳에서 펼쳐 본다.
- 지도 두 뷰는 서울 기본 선택, 시계열은 서울·경기 기본 선택이며 지역마다 선과 히트맵 행이 나오는지 확인한다.
- 같은 지역·월의 전년동월대비와 시작월=100 계산을 원자료와 대조한다. 선택한 모든 지역이 기준월에 100이고, 기준월 변경은 값에 반영되지만 X·Y축 확대는 값을 바꾸지 않는지 확인한다.
- 과거 증감률 자료가 있으면 원본 지수 이전 구간이 연결되고 누락 월에서 복원이 멈추는지, 자료가 없으면 원본 기간만 제공하는지 확인한다.
- 지역 추가·해제, 동명 시군구, 시작월 값이 없는 지역, 한 달 선택, 지도 지표·연월 변경을 실제 화면에서 조작한다. 히트맵 행 수, 회색 슬라이더, 세로 슬라이더 정렬, 드롭다운 글자 크기, V-World 지도 표시를 확인한다.
