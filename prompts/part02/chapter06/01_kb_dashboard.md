## KB부동산 대시보드 프롬프트 전체 문안

```text
### 먼저 할 일: 입력 데이터 확인

현재 작업 폴더의 파일과 데이터 저장소를 먼저 살펴본다. 이 프롬프트의 데이터 절에 적힌 각 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 실제 저장 위치와 형식, 필요한 정보와 실제 항목의 대응 관계, 기간 범위와 건수를 표로 요약한다.

파일명, 테이블명과 항목명을 추측하지 않는다. 필요한 자료나 정보가 없거나 같은 역할의 후보가 여러 개면 구현을 시작하지 말고, 찾은 후보와 확인이 필요한 내용을 먼저 알려준다.

### 1. 목적

KB부동산 데이터를 시군구 경계 지도(코로플레스 맵) 위에 시각화하여, 부동산 가격의 공간적 확산 패턴을 직관적으로 파악하는 대시보드를 구축한다.

- 매매가격 전년동월대비 증감률을 지도 위에 색상으로 표현

- 전세가격 전년동월대비 증감률을 지도 위에 색상으로 표현

- 전세가율을 지도 위에 색상으로 표현

- 매매 거래량을 시군구 단위로 집계하여 지도 위에 표현

- 선 그래프로 지역별 시계열 추이 비교

- 히트맵 테이블로 전체 지역의 시계열 변화 한눈에 조감

### 2. 구현 환경

- 스트림릿 웹 서비스: 지도 시각화 인터랙티브 대시보드

- 데이터베이스: 덕DB (읽기 전용)

- 패키지 관리: uv

### 3. 구현 언어: Python 3.14 이상

### 4. 데이터

현재 작업 폴더에서 다음 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 사용한다: KB부동산의 아파트 매매가격지수·전세가격지수·전세가율, 지역·계약 시점·거래가격과 거래 상태가 있는 아파트 매매 실거래, 시군구 행정경계 GeoJSON. 필요한 자료가 없거나 후보가 여러 개면 구현 전에 알려준다. 경계 자료의 좌표계도 확인한다.

### 5. 데이터 전처리

#### 1) 전년동월대비 증감률 계산

- KB 매매가격지수와 전세가격지수에서 각 지역의 전년 같은 달 대비 증감률을 계산한다

- 증감률(%) = (당월 지수 - 12개월 전 지수) / 12개월 전 지수 × 100

- 소수점 첫째 자리까지 표시

#### 2) 시군구별 거래량 집계

- 실제 아파트 매매 실거래 자료를 지역과 계약 연월 단위로 묶어 거래 건수를 계산한다

- 직거래 제외 (중개 거래만 사용), 취소 거래(해제 처리된 거래) 제외

- 시군구 주소를 KB 데이터 및 경계지도의 지역명과 매칭 가능하도록 정규화한다

#### 3) 경계지도 매칭

- GeoJSON의 시군구 속성명과 KB 데이터의 지역명을 매칭한다

- 매칭되지 않는 지역은 별도 처리 (세종특별자치시 등 특수 케이스)

### 6. 시각화

#### 뷰 1: 지도 대시보드 (2×2 코로플레스)

4개의 시군구 경계 지도를 2행 2열로 배치한다.

| 위치 | 지표 | 색상 스케일 |

|------|------|------------|

| 좌상 | 매매가격 전년동월대비 증감률 | 약함(파란) ↔ 강함(빨강): 0 기준 분기 색상 |

| 우상 | 전세가격 전년동월대비 증감률 | 약함(파란) ↔ 강함(빨강): 0 기준 분기 색상 |

| 좌하 | 전세가율 | 약함(파란) ↔ 강함(빨강): 중앙값 기준 분기 색상 |

| 우하 | 매매 거래량 | 약함(파란) ↔ 강함(빨강): 중앙값 기준 분기 색상 |

4개 지표 모두 동일한 파랑↔흰색↔빨강 색상 체계를 사용한다. 증감률은 0을 기준으로, 전세가율과 거래량은 조회 시점의 중앙값을 기준으로 지역 간 상대적 강도를 비교한다.

- 각 지도에 시군구명과 수치를 라벨로 표시 (예: "강남구 8.5%")

- 각 지도 상단에 지표명 제목 표시

- 배경 지도: 저채도 배경 (데이터에 집중하기 위해 최소한의 타일 사용)

#### 뷰 2: 지도 상세 (단일 지표 확대)

- 4개 지표 중 1개를 선택하여 큰 화면으로 표시한다

- 사이드바에서 지표를 변경하면 같은 배율에서 색상만 갱신된다

- 사용자가 확대/축소한 지도 배율은 시점 변경 시에도 유지된다

#### 뷰 3: 시계열 분석

- 선 그래프: 선택한 시도 또는 시군구들의 시계열 추이를 한 차트에 겹쳐서 표시. 지역별 색상으로 구분. 범례 표시.

- 히트맵 테이블: 행에 시군구, 열에 날짜(연월). 셀에 수치를 표시하고, 강도가 강하면 빨간색 계열, 약하면 파란색 계열로 셀 배경색을 적용한다. 색상 강도는 값의 크기에 비례한다.

- 시간 범위 슬라이더: 전체 기간 중 원하는 구간을 선택하여 차트와 테이블에 반영

### 7. 사용자 인터페이스

#### 뷰 전환

- 사이드바에서 뷰를 전환할 수 있다: "지도 대시보드", "지도 상세", "시계열 분석"

#### 지도 뷰 필터 (사이드바), 지도 대시보드, 지도 상세 공통

- 시도: 다중 선택 (기본값: 서울, 경기)

- 연월 이동: ◀▶ 버튼으로 이전월/다음월 이동 + 슬라이더로 대략적 위치 이동

- 지표 선택 (지도 상세 전용): 드롭다운 (4개 지표 중 택 1)

#### 시계열 분석 뷰 필터 (사이드바)

- 지표 선택: 드롭다운 (거래량 제외, KB 지수 기반 3개 지표)

- 시도: 다중 선택. 시도만 선택하고 시군구를 선택하지 않으면 시도별 비교가 된다

- 시군구: 다중 선택. 시도를 선택하면 해당 시도의 시군구만 목록에 표시되고, 시도를 선택하지 않으면 전체 시군구 목록이 표시된다. 시군구를 선택하면 시군구별 비교가 된다. 단, 동명 시군구(예: 강서구가 서울특별시·부산광역시 양쪽에 존재)가 있는 경우 목록에 "강서구 (서울특별시)" / "강서구 (부산광역시)" 형태로 시도명을 병기하여 구분한다

#### 시계열 분석 뷰 기간 선택 (메인 영역)

- 기간 선택: 시작~끝 범위 슬라이더 (연월 단위). 차트와 가까운 메인 영역에 배치하여 조작성을 높인다

```

## 파일로 저장한 프롬프트 전달

```text
첨부한 KB부동산 대시보드 요구사항을 모두 읽고, 구현 전에 다섯 종류의 입력 데이터와 지역 연결 검증 결과를 보여줘
```
