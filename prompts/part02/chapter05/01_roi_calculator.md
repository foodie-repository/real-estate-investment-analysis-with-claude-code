- 관련 코드: `projects/part07_roi/`

```text

## 프로젝트: 아파트 투자 수익률 계산기

### 먼저 할 일: 입력 데이터 확인

현재 작업 폴더의 파일과 데이터 저장소를 먼저 살펴본다.
이 프롬프트의 데이터 절에 적힌 각 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 실제 저장 위치와 형식, 필요한 정보와 실제 항목의 대응 관계, 기간 범위와 건수를 표로 요약한다.

파일명, 테이블명과 항목명을 추측하지 않는다.
필요한 자료나 정보가 없거나 같은 역할의 후보가 여러 개면 구현을 시작하지 말고, 찾은 후보와 확인이 필요한 내용을 먼저 알려준다.

### 1. 목적

매수 시점과 보유 기간을 지정하면, 분석 대상 단지별 투자 수익률을 자동으로 계산하여 구글 시트에 정리한다.

### 2. 데이터

현재 작업 폴더에서 다음 세 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 사용한다: ① 지역·단지·전용면적·계약 시점·거래가격과 거래 상태가 있는 아파트 매매 실거래, ② 보증금·월세 정보로 전세를 구분할 수 있는 아파트 임대차 실거래, ③ 세대수와 건축연도가 있는 공동주택 기본정보.
필요한 자료가 없거나 후보가 여러 개면 구현 전에 알려준다.

### 3. 분석 대상 단지 관리

- 분석 대상 단지 목록을 별도 파일로 저장한다

- 각 항목: 시군구, 단지명, 전용면적(㎡)

- 단지를 추가할 때 실제 아파트 매매 실거래 자료에서 단지 존재 여부와 거래 가능한 전용면적을 확인한다

- 같은 이름의 단지가 여러 지역에 있으면 사용자가 고른 전체 시군구를 함께 저장한다

- 허용 범위 안에 여러 면적이 있으면 사용자가 입력한 값과 가장 가까운 실제 전용면적을 저장한다

- 가격 조회는 저장된 전용면적과 차이가 1㎡ 미만인 거래만 사용한다

- 추가, 삭제, 전체 목록 조회 기능을 제공한다

- 삭제할 때 같은 단지명·면적의 항목이 여러 지역에 있으면 임의로 모두 지우지 않고 시군구를 다시 요청한다. 시군구가 지정되면 해당 지역의 한 항목만 삭제한다

### 4. 수익률 계산 기준

#### 입력 파라미터

- 매수 시점: 년월 (예: 2020년 1월). 사용자가 지정한다

- 비교 기간: 보유 기간 목록 (기본값: \[2, 4\]년). 사용자가 변경 가능하다

#### 계산 공식

- 갭(투자금) = 매매가 - 전세가. 각 시점마다 계산한다

- 매매차익 = 비교시점 매매가 - 매수시점 매매가

- 수익률(%) = 매매차익 ÷ 매수시점 갭 × 100

- 비교 시점 = 매수 시점 + 보유 기간. 동일 월 기준이다 (매수 2020년 1월, 보유 2년이면 비교 시점은 2022년 1월)

- 세전 기준으로 계산한다

#### 가격 조회 규칙

- 해당 월에 거래가 있으면 그 거래의 가격을 사용한다. 같은 월에 여러 건이면 가장 최근 계약일의 거래를 사용한다

- 해당 월에 거래가 없으면, 가장 가까운 시점의 거래를 사용한다

- 1년 이상 거래가 없는 경우에는 공란으로 표시한다

- 매매는 거래유형이 `직거래`인 건을 제외한다

- 계약이 취소된 거래는 제외한다

- 전세가 조회 시 전세만 사용한다 (월세 제외)

- 전월세 자료에 해제사유발생일 항목이 없으면 매매와 같은 취소 필터를 적용했다고 쓰지 않는다

### 5. 구글 시트 출력

#### 단지 정보 (왼쪽 영역)

- 시도, 시군구, 읍면동

- 단지명, 전용면적, 평형 (전용면적 기반 추정평형)

- 세대수: 공동주택 기본정보에서 매칭

- 건축연도

#### 매수 시점 (중앙 영역)

- 매매가: 매수 시점의 매매가

- 전세가: 매수 시점의 전세가

- 갭: 매매가 - 전세가 (초기 투자금)

#### 비교 시점별 수익률 (오른쪽 영역, 기간 수만큼 반복)

각 비교 시점마다 다음 5개 항목:

- 매매가: 비교 시점의 매매가

- 전세가: 비교 시점의 전세가

- 갭: 비교 시점의 매매가 - 전세가

- 매매차익: 비교시점 매매가 - 매수시점 매매가

- 수익률(%): 매매차익 ÷ 매수시점 갭 × 100

#### 시트 설정

- 첫 번째 행: 헤더.
실제 연도를 표시한다.
매수 시점이 2020년 1월이면 "2020.1 매매가", "2020.1 전세가", "2020.1 갭", 2년후는 "2022.1 매매가", "2022.1 전세가", "2022.1 갭", "2년 매매차익", "2년 수익률(%)" 형태다

- 분석 대상 단지별 한 행씩 기록

- 실행 시 기존 데이터를 새 데이터로 교체

- 매수 시점과 비교 기간, 마지막 업데이트 일시를 시트에 표기

### 6. 설정

- 구글 시트 ID, 서비스 계정 키 파일 경로 등 민감한 설정은 .env 파일로 관리한다

- 현재 프로젝트에 이미 연결된 구글 서비스 계정이 있으면 재사용한다. 없으면 필요한 설정 절차를 먼저 안내한다
```
