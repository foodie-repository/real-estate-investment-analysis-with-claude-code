```text

## 프로젝트: 아파트 거래량 랭킹 지도 만들기

### 먼저 할 일: 입력 데이터 확인

현재 작업 폴더의 파일과 데이터 저장소를 먼저 살펴본다.
이 프롬프트의 데이터 절에 적힌 각 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 실제 저장 위치와 형식, 필요한 정보와 실제 항목의 대응 관계, 기간 범위와 건수를 표로 요약한다.

파일명, 테이블명과 항목명을 추측하지 않는다.
필요한 자료나 정보가 없거나 같은 역할의 후보가 여러 개면 구현을 시작하지 말고, 찾은 후보와 확인이 필요한 내용을 먼저 알려준다.

### 1. 목적: 지도 시각화로 한눈에 보기

- 거래량 많은 단지 랭킹 시각화: 매매, 전세, 월세

- 회전율 높은 단지 랭킹 시각화: 매매, 전세, 월세

### 2. 구현 환경

- 스트림릿 웹 서비스: 지도 시각화 인터랙티브 서비스

- 데이터베이스: 덕DB (읽기 전용)

- 패키지 관리: uv

### 3. 구현 언어: Python 3.11 이상

### 4. 데이터

현재 작업 폴더에서 다음 네 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 사용한다: ① 아파트 매매 실거래, ② 보증금과 월세 정보로 전세·월세를 구분할 수 있는 아파트 임대차 실거래, ③ 세대수가 있는 공동주택 기본정보, ④ 카카오 지오코딩으로 만든 주소별 위도·경도.
필요한 자료가 없거나 후보가 여러 개면 구현 전에 알려준다.

공동주택 기본정보는 `단지구분코드='1'`인 아파트만 사용한다.

매매와 임대차를 합치지 않고 거래유형별로 따로 집계한다.
임대차는 전월세구분으로 전세와 월세를 나눈다.

매매는 해제사유발생일이 유효한 취소 거래를 제외한다.
해제사유발생일이 NULL, 빈 문자열, 'None', '-'인 기록만 남기며, 이 항목이 없는 임대차에는 취소 필터를 적용하지 않는다.

매매의 직거래와 중개거래를 구분해 검증하되, 거래량 랭킹에는 둘 다 포함한다.
가격을 해석할 때는 직거래를 따로 확인할 수 있게 한다.

### 5. 데이터 전처리

#### 1) 전용면적 분류 (실무 관용 5단계)

- 전용면적을 다음 다섯 구간으로 분류한다

- 초소형: 전용면적 40㎡ 이하

- 소형: 전용면적 40㎡ 초과 ~ 60㎡ 이하

- 중소형: 전용면적 60㎡ 초과 ~ 85㎡ 이하

- 중대형: 전용면적 85㎡ 초과 ~ 135㎡ 이하

- 대형: 전용면적 135㎡ 초과

#### 2) 추정평형 계산 및 평형대 분류 (7단계)

- 추정평형 = 전용면적(㎡) x 0.4

- 평형대 구간은 반올림 전 추정평형을 기준으로 나누고, 화면 표시값만 필요할 때 반올림한다

- 평형대: 10평 미만, 10평대, 20평대, 30평대, 40평대, 50평대, 60평 이상

#### 3) 주소 파싱

- 지역 문자열(예: "서울특별시 강남구 압구정동")을 시도·시군구·읍면동으로 분리

- 세종특별자치시는 시군구에 '세종시'로 대체

#### 4) 날짜/연식 항목 생성

- 계약 시점에서 계약연도를 계산한다

- 연식 = 현재 연도 - 건축연도 (최소 1년)

- 연식을 5년 미만, 5~10년, 10~20년, 20~30년, 30년 이상으로 구분한다

#### 5) 좌표 매칭

- 실거래 기록에서 시도·시군구·도로명을 결합한 지역 포함 도로명주소 키를 만들고, 카카오 지오코딩으로 만든 주소별 위도·경도 자료의 같은 키와 연결한다.
도 단위 주소는 도와 시·군을 포함하고, 세종특별자치시는 세종시를 보완한다

- 직접 연결되지 않으면 같은 시도·시군구·읍면동·단지 범위에서만 후보를 검토한다.
임의의 근처 좌표를 붙이지 말고, 연결 전후 행 수·고유 단지 수·누락 주소와 보정 근거를 보여준다

#### 6) 세대수 매칭 및 회전율 계산

- 공동주택 기본정보와 실거래 기록을 지역·단지 기준으로 연결한다.
동명 단지가 여러 개면 임의로 합치지 말고 가장 타당한 후보를 선택한다

- 회전율 = 선택한 거래유형·기간·면적 조건의 거래량 / 세대수(단지 전체) x 100

- 세대수는 면적대 필터와 무관하게 항상 단지 전체 세대수 사용

- 여러 해를 선택한 경우 회전율은 해당 기간의 누적 회전율이며 연평균처럼 표현하지 않는다

- 소수점 둘째 자리까지 표시

- 세대수 매칭이 안 되는 단지는 회전율 "정보 없음" 표시

### 6. 시각화

#### 지도

- 배경 지도: V-World Map

- 랭킹 원(번호) 마커로 표시

#### 원 마커

- 색상: 연식 구간에 따라 구분

- 랭킹 숫자를 원 안에 표시 (흰색)

#### 툴팁

- 단지명 (굵게)

- 시도 시군구 읍면동

- 건축연도 (연식 구간)

- 거래량

- 세대수 (매칭 안 되면 "정보 없음")

- 회전율 (매칭 안 되면 "정보 없음")

#### 범례

- 오른쪽 사이드에 연식 구간별 색상 범례 표시

- 전체 건수 중 세대수 매칭 건수 표시

#### 랭킹 테이블

- 지도 아래에 표 형태로 표시

- 항목: 순위, 단지명, 시군구, 읍면동, 건축연도, 연식 구간, 거래량, (세대수, 회전율)

- 거래량 또는 회전율 기준 정렬

- 거래량 상위 또는 회전율 상위를 유망 단지 순위로 표현하지 않는다.
표본 수, 세대수 매칭 여부, 거래 구성과 가격을 추가로 확인할 후보 목록임을 화면에 안내한다

### 7. 사용자 인터페이스 (사이드바)

#### 필수 선택

- 거래유형: 매매, 전세, 월세 (라디오 버튼)

- 시도: 여러 지역을 선택할 수 있게 하고 기본값은 서울특별시로 한다

#### 랭킹 설정

- 랭킹 기준: 거래량, 회전율 (라디오 버튼)

- 랭킹 표시 개수: 10, 20, 30, 40, 50개 중 선택하며 기본값은 20개로 한다

#### 지역을 단계별로 선택

- 시도 선택 → 해당 시군구 목록 갱신

- 시군구 선택 → 해당 읍면동 목록 갱신 (시군구 미선택 시 시도 전체)

- 복수 시도 선택 시, 동명 시군구(예: 강서구가 서울특별시·부산광역시 양쪽에 존재)가 있으면 목록에 "강서구 (서울특별시)" / "강서구 (부산광역시)" 형태로 시도명을 병기하여 구분한다.
단일 시도 선택 시에는 시도명 없이 시군구명만 표시한다

- 기본값: 서울특별시 강남구

#### 기간 선택

- 기본 모드: 단일 연도 슬라이더 + 이전/다음 버튼

- ‘기간 범위 모드’를 선택하면 시작 연도와 종료 연도를 함께 고를 수 있게 한다

#### 면적 필터

- 면적대: 다섯 구간 중 여러 개를 선택할 수 있게 하고 기본값은 전체로 한다

- 평형대: 10평 미만부터 60평 이상까지 여러 개를 선택할 수 있게 하고 기본값은 전체로 한다

#### 기타

- 세대수 범위 지정: 체크박스 → 최솟값/최댓값 직접 입력

- 지도 스타일 선택: 기본지도, 위성지도, 하이브리드
```
