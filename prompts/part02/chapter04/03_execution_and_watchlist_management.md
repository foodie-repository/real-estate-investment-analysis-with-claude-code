# P02-C04-S03 실행과 관심단지 관리

- 책 위치: 2부 4장 4.3
- 필요한 준비: 4.2절에서 만든 트래킹 기능, 구글 스프레드시트, 서비스 계정 JSON 키 파일
- 관련 코드: [`projects/part04_tracking/`](../../../projects/part04_tracking/)

## 관심단지 트래킹 기능 시험

```text
관심단지 시세 트래킹 기능을 시험해줘. 등록된 관심단지 목록을 읽고 지역·단지명·전용면적을 보여줘. 등록된 항목이 없으면 오류를 내거나 임의의 단지를 추가하지 말고 0건이라고 알려준 뒤 종료해줘. 항목이 있으면 시세 계산 직전까지 필요한 매매·임대차 실거래와 공동주택 기본정보가 연결되는지 확인해줘.
```

## 구글 스프레드시트 연결

대괄호 안의 자리표시자를 실제 스프레드시트 ID로 바꿔 입력합니다. 서비스 계정 JSON 키 파일의 실제 내용은 대화창에 붙여넣지 마세요.

```text
관심단지 시세 트래킹 결과를 저장할 구글 스프레드시트를 연결해줘.

스프레드시트 ID는 [구글 시트 URL에서 복사한 ID]야.

프로젝트 폴더에서 구글 서비스 계정 JSON 키 파일을 찾아 현재 프로젝트의 설정 방식에 맞게 연결해줘. 후보가 없거나 여러 개면 파일을 임의로 고르지 말고 경로 목록과 필요한 조치를 알려줘. 키 파일이 깃에 포함되지 않는지도 확인해줘.
```

## 단지 검색

```text
관심단지 시세 트래킹 목록에 등록하기 전에, 현재 작업 폴더에서 식별한 아파트 매매 실거래 자료에서 '고덕그라시움'을 검색해줘. 지역, 정확한 단지명, 거래 가능한 전용면적과 수록 기간을 보여주고 목록은 아직 수정하지 마.
```

## 단지 추가

```text
관심단지 시세 트래킹 목록에 고덕그라시움 전용면적 84.24㎡를 추가해줘. 매매 실거래에서 지역·단지명·면적이 실제로 확인될 때만 추가하고 결과를 알려줘.
```

```text
관심단지 시세 트래킹 목록에 래미안솔베뉴 전용면적 59.29㎡를 추가해줘. 매매 실거래에서 실제 존재를 확인한 뒤 추가해줘.
```

```text
관심단지 시세 트래킹 목록에 헬리오시티 전용면적 84.98㎡를 추가해줘. 매매 실거래에서 실제 존재를 확인한 뒤 추가해줘.
```

## 관심단지 목록 조회

```text
관심단지 시세 트래킹 목록을 수정하지 말고 조회해 지역, 단지명과 전용면적을 표로 보여줘. 등록된 항목이 없으면 0건이라고 알려줘.
```

## 단지 삭제

```text
관심단지 시세 트래킹 목록에서 래미안솔베뉴 전용면적 59.29㎡만 삭제해줘. 같은 이름의 다른 단지나 다른 면적은 삭제하지 말고, 삭제 전후 목록을 보여줘.
```

## 트래킹 실행

```text
등록된 관심단지 목록을 불러와 시세 트래킹을 실행해줘. 각 단지·전용면적에 대해 최근 중개 매매가, 최근 전세 보증금, 전월 대비 변동, 매매-전세 갭, 전세가율, 역대 최고 매매가 대비 등락률, 세대수와 건축연도를 계산해줘. 직거래와 취소 거래는 제외하고 월세 보증금을 전세가로 사용하지 마. 결과를 연결된 구글 시트에 기록하되 설정이 없으면 화면에 표로 보여줘. 완료 후 성공·실패 건수와 이유, 마지막 업데이트 시각과 결과 위치를 알려줘.
```

트래킹 결과에 최근 3개월 평균 매매가를 추가해줘
