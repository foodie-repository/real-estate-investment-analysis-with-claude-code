### 1. 목표와 구현 환경

매매·전세·월세의 거래량 또는 회전율 상위 단지를 지도와 표로 함께 보여주는 Streamlit 대시보드를 만든다. 화면 제목과 브라우저 제목은 "아파트 거래량 랭킹 지도"로 하고, 페이지 아이콘은 집 모양으로 한다.

현재 프로젝트의 Python과 uv 환경을 사용한다. Python 3.11 이상과 기존 의존성 설정을 유지하고, DuckDB는 읽기 전용으로 연결한다. 지도는 Folium과 streamlit-folium을 사용한다. 구현 파일은 projects/part08_trade_map/dashboard/ 아래에 두고 app.py로 실행한다. 기존 공통 설정과 주소 처리 모듈이 있으면 재사용한다. 원본 데이터, 다른 장의 대시보드와 공통 설정을 임의로 변경하지 않는다.

### 2. 먼저 할 일: 사용할 데이터와 수록 범위 확인

현재 작업 폴더에서 다음 네 자료를 이름이 아니라 내용과 출처를 기준으로 확인한다.

- 아파트 매매 실거래: 지역, 단지명, 전용면적, 계약 시점, 건축연도, 도로명, 계약 해제 여부가 있는 자료.
- 아파트 임대차 실거래: 위 정보와 전세·월세 구분이 있는 자료. 구분 항목이 없으면 월세가 0인 계약을 전세, 0보다 큰 계약을 월세로 분류한다.
- 공동주택 기본정보: 주소, 단지명, 주택 유형, 단지 전체 세대수가 있는 자료.
- 카카오 지오코딩으로 만든 주소별 위도·경도.

데이터베이스는 환경변수 TRADE_MAP_DB_PATH가 지정되면 그 파일을 우선하고, 없으면 프로젝트의 기본 DB인 data/apt_investment.duckdb를 사용한다. 지정된 파일을 열 수 없으면 다른 DB로 몰래 바꾸지 말고 경로 확인을 안내한다. 경로나 API 키를 코드에 직접 넣지 않는다.

선택한 DB의 자료별 실제 저장 이름, 필요한 정보와 실제 항목의 대응 관계, 거래유형별 수록 시도·기간·건수를 먼저 표로 보고한다. 필요한 자료가 없거나 선택한 DB 안에서 자료 후보를 구분할 수 없으면 구현 전에 확인한다. 필수 자료가 확인되면 아래 요구사항에 따라 구현과 실행 검증까지 이어서 수행한다.

데이터 탐색은 DB에 저장된 기본 테이블과 그 항목부터 확인한다. 이번 지도와 관계없는 뷰나 외부 파일 참조를 전부 실행하지 않는다. 관련 없는 뷰가 존재하지 않는 파일을 참조하더라도 필요한 네 기본 자료를 읽을 수 있으면 구현을 계속한다. 자료의 선택 근거는 보고하되, 별도 상품성 분석이나 다른 장의 자료를 요구하지 않는다.

앞 장의 수집 결과인 매매, 전월세, 공동주택_전국, 좌표 테이블이 존재하고 위의 필수 정보를 갖추었으면 이 네 자료를 사용한다. 다른 이름으로 저장되어 있으면 각 자료의 필수 정보를 모두 확인해 대응한다. 전용면적과 계약년월이 있다는 이유만으로 매매 후보로 분류하지 않는다. 건축연도·도로명 등이 없는 분양권전매나 다른 주택 유형의 자료는 이 아파트 거래 지도에 사용할 매매 자료가 아니다.

매매 자료의 "거래유형"은 중개거래·직거래·"-" 등을 나타내는 거래 방식이며 임대차 자료라는 뜻이 아니다. 이 항목이 있어도 매매 자료로 사용하고 거래 방식으로 제외하지 않는다. 전세·월세 구분은 전월세 자료의 "전월세구분"을 사용한다. 이름이 다른 항목에 대응할 때도 실제 저장값과 자료 출처를 확인하고, "거래유형"이라는 이름만으로 전월세구분의 별칭으로 처리하지 않는다.

지역이 하나의 문자열에 들어 있는 자료와 시도·시군구·읍면동·리가 각각 나뉜 자료를 모두 지원한다. 전용면적 항목도 단위가 이름에 붙은 경우와 붙지 않은 경우를 확인해 대응한다. 이미 분리된 시군구를 전체 주소로 오해해 다시 나누지 않는다.

시도 선택지는 선택한 거래유형의 실제 수록 지역에서 만든다. 전국 자료라면 서울 밖의 시도도 선택할 수 있어야 한다. 서울 자료만 있는 DB에 전국 목록이나 가짜 데이터를 추가하지 않는다. 이때 서울만 보이는 이유와 다른 지역 자료가 있는 DB를 지정하는 방법은 완료 보고에서 설명하고, 대시보드에 별도 안내 문단을 추가하지 않는다.

지역 선택지와 연도 범위는 거래유형만 구분한 원본 자료에서 구한다. 지도용 취소·도로명·건축연도·좌표 필터 때문에 지역이나 연도 선택지가 줄어들지 않게 한다. 빈 지역 항목은 목록에서 제외한다.

### 3. 거래량과 회전율 계산 규칙

- 매매의 취소·해제 거래는 제외한다. 현재 수집 자료의 해제일이 비어 있거나 NULL, "None", "-", 빈 문자열이면 유효 거래로 취급한다. 직거래라는 이유만으로 제외하지 않는다. 임대차는 선택한 전세 또는 월세만 남기며 신규·갱신을 임의로 제한하지 않는다.
- 지역 정보가 없거나 도로명이 NULL·빈 문자열·공백뿐인 행, 건축연도가 없거나 0 이하인 행은 지도 집계에서 제외한다. 도로명은 앞뒤 공백을 정리한 뒤 비어 있는지 판단한다.
- 전용면적은 초소형(40㎡ 이하), 소형(40㎡ 초과~60㎡ 이하), 중소형(60㎡ 초과~85㎡ 이하), 중대형(85㎡ 초과~135㎡ 이하), 대형(135㎡ 초과)으로 구분한다.
- 추정평형은 전용면적 × 0.4로 계산한다. 평형대를 나누기 전에 반올림하지 않는다. 10평 미만, 10평대(10 이상~20 미만), 20평대, 30평대, 40평대, 50평대, 60평 이상으로 구분한다.
- 계약 시점에서 계약연도를 구한다. 연식은 현재 연도에서 건축연도를 빼되 최소 1년으로 한다. 연식 구간은 5년 미만, 5년 이상~10년 미만, 10년 이상~20년 미만, 20년 이상~30년 미만, 30년 이상이다.
- 지역 주소는 연속 공백을 정리하고 시도·시군구·읍면동으로 나눈다. 시군구가 "성남시 분당구"처럼 두 단계이면 이를 보존한다. 분리된 자료의 읍면동과 리는 함께 유지하고, 세종특별자치시의 빈 시군구는 "세종시"로 표시한다.
- 선택한 지역·기간·면적대·평형대 조건을 모두 적용한 뒤 거래 건수를 집계한다. 같은 시도·시군구·읍면동·단지명의 면적대별·연도별 거래량은 합산해 지도와 랭킹 표에서 단지 하나를 한 번만 표시한다. 여러 연도를 선택하면 해당 기간의 누적 거래량과 누적 회전율이며 연평균으로 바꾸지 않는다.
- 좌표는 도로명만으로 연결하지 않고 시도·시군구를 포함한 도로명주소로 연결한다. 좌표 자료의 주소 형식에 맞춰 특별시·광역시는 시도+구+도로명, 도 지역은 도+시·군+도로명, 세종은 세종특별자치시+세종시+도로명으로 맞춘다. 기존 공통 주소 키 규칙이 있으면 따른다.
- 거래 쪽 도로명주소 키와 좌표 쪽 주소 모두 앞뒤 공백을 제거하고 연속 공백을 하나로 줄인 뒤 정확히 연결한다. 위도·경도가 모두 있는 좌표만 사용한다. 정리한 주소가 중복되면 경도 오름차순, 위도 오름차순의 첫 행 한 쌍만 남겨 거래량이 중복 증가하지 않게 한다. 위도와 경도를 서로 다른 행에서 따로 고르지 않는다.
- 지역·기간·면적 조건을 먼저 적용하고 집계한 뒤, 읍면동이 누락된 행은 같은 시도·시군구·단지명의 원본 거래에서 가장 자주 나오는 읍면동으로 보정한다. 좌표 후보도 원본 거래 전체에서 찾는다. 임대차의 보정 후보는 전세·월세를 합친 원본 전체다. 이 보정 후보를 선택한 연도·면적이나 취소 제외 조건으로 좁히지 않는다. 같은 시도·시군구·읍면동·단지명에 여러 도로명주소가 있으면 정리한 주소 길이 내림차순, 주소 문자열 오름차순, 경도 오름차순, 위도 오름차순으로 첫 좌표 한 쌍을 선택한다. 근처의 다른 단지 좌표를 임의로 붙이지 않는다. 건물번호 없는 주소도 정확히 연결되면 기존 자료의 좌표를 사용하지만, 도로 수준 좌표일 수 있어 단지 위치 정확도를 보장하지 못한다는 한계를 검증 결과에 밝힌다. 보정 후에도 위도·경도가 없으면 지도와 랭킹 표에서 모두 제외한다.
- 좌표 보정 후보에는 원본 읍면동과 공백을 정리한 도로명이 모두 비어 있지 않은 행만 사용한다. 도로명이 NULL·공백인 행에 지역 이름만 붙여 시군구 중심점 좌표와 연결하지 않는다. 읍면동을 보정한 대상 행은 보정된 읍면동과 같은 단지의 위 유효 후보를 찾고, 후보가 없으면 해당 거래 행의 유효 도로명주소에 직접 연결된 좌표를 사용한다. 어느 쪽도 없으면 제외한다.
- 세대수는 공동주택 기본정보 중 아파트만 사용한다. 실거래와 공동주택 주소는 먼저 앞뒤 공백을 없애고 연속 공백을 하나로 줄인다. 공동주택 주소 끝의 숫자 지번·하이픈 지번과 `가-` 같은 임시 지번 표기를 제거하여 지역 주소 키를 만든다. 실거래 쪽 지역 주소 키는 일반 지역에서 시도+시군구+읍면동·리로 만들고, 세종특별자치시는 화면에 표시하는 `세종시`를 넣지 않은 시도+읍면동·리로 만든다. 공동주택 원자료에 없는 시군구를 추정해 추가하지 않는다.
- 공동주택 기본정보에 `단지명` 외에 공시가격·건축물대장·도로명주소 출처의 단지명 항목이 있으면 비어 있지 않은 이름을 모두 정확 매칭 후보로 사용한다. 이름 비교에서는 공백과 괄호 같은 구분 기호를 정리한다. `범지기마을10단지(대우푸르지오)`와 `대우푸르지오(10단지)`처럼 괄호 안 브랜드명과 `N단지`의 순서만 바뀐 경우에는 브랜드명+`N단지` 키를 양쪽에서 만들어 정확히 연결한다. 주소를 무시한 유사도·부분 문자열 매칭으로 다른 단지를 붙이지 않는다. 같은 지역·정규화 이름 후보가 여러 행이면 가장 큰 세대수 한 건만 사용해 거래량이 중복 증가하지 않게 한다. 연결 전후의 집계 행 수가 같고 한 거래 집계 행이 여러 공동주택 행으로 늘어나지 않는지 확인하며, 여전히 연결되지 않은 단지는 `정보 없음`으로 유지하고 누락·동명 단지 위험을 검증 결과에 설명한다.
- 단지의 회전율은 합산 거래량 ÷ 단지 전체 세대수 × 100으로 다시 계산하고 소수점 둘째 자리까지 반올림한다. 면적대를 좁혀도 분모는 단지 전체 세대수다. 세대수가 없거나 0 이하이면 회전율을 계산하지 않는다. 거래량 랭킹에는 남기고 회전율 랭킹에서는 제외한다.
- 세대수 범위를 지정하면 세대수가 확인된 단지에만 최소값·최대값을 적용한다. 세대수 미확인 단지는 거래량 랭킹에 남긴다.
- 거래량 또는 회전율의 내림차순으로 상위 N개를 고르고 지도와 표에 같은 순서로 표시한다. 동률은 같은 값임을 유지하며, 동률끼리의 순서에 따라 값이나 지도·표 대응이 달라지지 않게 한다.
- 같은 단지에 여러 건축연도가 있으면, 필터·연결을 마친 면적대별·연도별 집계 행 중 거래량이 가장 많은 행의 건축연도·연식 구간·좌표를 대표값으로 사용한다. 단순 최빈 건축연도로 바꾸지 않는다.
- 기존 예제와 동률의 표시 순서까지 맞추기 위한 호환 규칙: 최종 집계 행을 거래량 내림차순으로 정렬한 후, 시도·시군구·읍면동·단지명 순서로 단지를 묶고 거래량은 합계, 나머지 대표 항목은 첫 유효값을 사용한다. 단지별 결과는 이 네 지역·이름 항목의 오름차순으로 준비한 다음, 랭킹 지표 하나만으로 Pandas의 기본 sort_values 내림차순 정렬을 적용하고 상위 N개를 취한다. 동률에 별도의 이름순 정렬을 추가하지 않는다. 이 작은 최종 집계 결과에만 Pandas를 사용하며 원본 자료 전체를 불러오지 않는다. 같은 순위를 비교할 때는 프로젝트의 잠금 파일에 기록된 패키지 버전도 맞춘다.
- 원본 전체를 Python 메모리에 올리지 않는다. 지역·기간 필터와 집계는 DuckDB에서 처리하고 화면에 필요한 집계 결과만 가져온다. 지역 선택지와 연도 범위는 거래유형별로 캐시한다.

### 4. 사이드바: 순서·문구·기본값

사이드바 제목은 st.sidebar.header("필터 설정")로 한다. st.title로 키우지 않는다. 아래 순서와 입력 방식을 지킨다.

1. "거래유형": 매매, 전세, 월세를 가로 라디오 버튼으로 배치한다. 기본값은 매매다.
2. "랭킹 기준": 거래량, 회전율을 가로 라디오 버튼으로 배치한다. 기본값은 거래량이다.
3. "랭킹 표시 개수": 10, 20, 30, 40, 50을 고르는 선택 슬라이더로 하고 기본값은 50이다.
4. 구분선 뒤에 "시도", "시군구", "읍면동"을 순서대로 배치한다. 모두 여러 항목을 고르는 선택 상자다. 기본값은 서울특별시·강남구이며 읍면동은 미선택이다. 해당 지역이 수록되지 않았으면 실제 선택지 안에서 초기화한다.
5. 시도 선택에 따라 시군구 목록을 갱신하고, 시군구 선택에 따라 읍면동 목록을 갱신한다. 시군구 미선택은 선택한 시도 전체, 읍면동 미선택은 선택한 시군구 전체를 뜻한다. 복수 시도에서 이름이 같은 시군구만 "강서구 (서울특별시)", "강서구 (부산광역시)"처럼 구분한다. 그 밖에는 시군구명만 표시한다. 읍면동도 이름만 표시한다. 목록은 표시 이름 오름차순이며 같은 읍면동 이름은 한 번만 보여준다. 강남구가 선택지에 없으면 시군구 초기값은 미선택이다.
6. 구분선 뒤에 "기간 범위 모드" 체크박스를 두고 기본은 해제한다. "기간 (연도)" 슬라이더의 범위는 선택한 거래유형의 실제 최소·최대 계약연도다. 단일 연도의 기본값은 최신 수록 연도이며, 아래에 "◀ 이전", "다음 ▶" 버튼을 같은 너비로 나란히 둔다. 한 번 누를 때 1년씩 이동하고 수록 범위를 벗어나지 않는다. 양쪽 버튼은 경계에서도 활성 상태를 유지하되 범위 밖으로 이동하려는 클릭은 현재 연도를 유지한다. 거래유형을 바꿔도 사용자가 고른 연도를 유지하고, 새 수록 범위를 벗어날 때만 가장 가까운 경계 연도로 제한한다. 위젯의 범위 변경이나 숨김으로 선택값이 사라지지 않도록 별도 상태를 유지한다. 기본값과 Session State를 중복 지정했다는 경고가 나오지 않게 한다.
7. 기간 범위 모드를 켜면 시작·종료 연도를 함께 고르는 슬라이더로 바꾸고 이전·다음 버튼은 숨긴다. 초기 범위는 최신 연도와 그 전 연도이며 최소 수록 연도보다 작아지지 않게 한다. 이후에는 사용자가 고른 범위를 유지하며 거래유형 변경 시 두 끝점을 각각 새 수록 범위 안으로 제한한다. 단일 연도와 범위 선택값은 따로 보존하여 모드를 껐다 켜도 복원한다. 한 연도만 수록된 자료에서는 슬라이더와 이전·다음 버튼 대신 사이드바 캡션으로 "기간 (연도): 2025년"처럼 해당 연도를 보여주고 두 모드 모두 그 연도로 조회한다.
8. 구분선 뒤에 "면적대 (전용면적 구분)"와 "평형대 (추정평형 구분)"를 여러 항목 선택 상자로 둔다. 앞에서 정의한 순서를 사용하고 처음에는 모든 항목을 선택한다. 선택을 모두 비우면 그 면적 조건은 제한하지 않는다.
9. 구분선 뒤에 "세대수 범위 지정" 체크박스를 두고 기본은 해제한다. 켜면 "최소 세대수"와 "최대 세대수" 숫자 입력을 나란히 보여준다. 최소값의 기본은 0, 최대값의 기본은 공동주택 자료 전체에서 주택 유형을 제한하지 않고 찾은 최대 세대수를 1,000 단위로 올림한 값이다. 1세대 단위로 입력하며 입력한 최소가 최대보다 크면 두 값을 바꿔 적용한다.
10. 마지막에 "지도 스타일" 단일 선택 상자를 두고 기본지도, 위성지도, 하이브리드 순서로 표시한다. 기본값은 기본지도다.

### 5. 화면 배치와 크기

- Streamlit의 넓은 화면 배치를 사용한다. 기본 밝은 테마에서 .block-container의 padding-top은 1rem, padding-bottom은 0으로 하고 header에는 visibility: hidden을 적용한다. display: none으로 헤더 영역 자체를 없애지 않는다. 별도 카드나 탭, KPI 영역을 추가하지 않는다.
- 본문은 제목 → 필터 요약 → 지도와 오른쪽 범례 → "랭킹 테이블" 순서로 배치한다. 필터 요약은 작은 회색 캡션(st.caption)으로 "서울특별시 강남구 | 2026년 | 매매 | 거래량 상위 50개" 형식이며 실제 선택값으로 갱신한다. 여러 연도이면 "2025~2026년"처럼 표시한다. 지역 부분은 굵게 한다. 여러 지역은 시도 목록, 시군구 목록, 읍면동 목록 순서로 연결하고 각 목록 안에서는 쉼표로 구분한다.
- 지도와 범례의 가로 비율은 6:1, 지도 높이는 750px로 한다. 지도는 해당 열 너비에 맞춘다.
- 사이드바는 가격·갭 대시보드와 같은 작은 글자와 촘촘한 선택 목록을 사용한다. 라벨, 선택 상자와 검색 입력, 선택된 태그, 숫자 입력, 라디오 항목, 캡션의 글자 크기는 0.8125rem(기본 13px)이다.
- 사이드바의 펼쳐진 선택 목록도 같은 실효 글자 크기 13px와 줄 높이 1.4를 적용한다. Streamlit의 가상 목록 전체를 0.64배로 축소하되 내부 글자 크기를 0.8125rem ÷ 0.64로 보정한다. 행의 위치·높이와 스크롤 영역을 함께 맞춰 항목이 겹치거나 잘리지 않게 한다. 본문 표와 지도에는 이 축소를 적용하지 않는다.
- 펼쳐진 목록 밖의 줄 높이, 필터 사이 여백과 구분선 여백은 Streamlit 기본값을 유지한다. 모든 사이드바 문단에 줄 높이 1.4를 일괄 적용하거나 구분선 여백을 줄이지 않는다. 가상 선택 목록의 stSelectboxVirtualDropdown 영역 전체에만 zoom: 0.64와 width: 100%를 적용하고, 펼쳐진 옵션 글자의 크기를 보정한다.
- 글자 크기 CSS는 사이드바 안의 [data-testid="stWidgetLabel"] p, [data-baseweb="select"], [data-baseweb="select"] input, [data-baseweb="tag"], [data-testid="stNumberInput"] input, [data-testid="stRadio"] p, [data-testid="stCaptionContainer"] p에만 적용한다. 사이드바 전체 p·label·input에 일괄 적용하지 않는다. 특히 제목과 이전·다음 버튼 글자는 기본 크기를 유지한다. 펼친 목록 CSS는 body:has([data-testid="stSidebar"] [role="combobox"][aria-expanded="true"]) 아래의 가상 목록과 :is([role="option"], [role="option"] div)에 적용한다.
- 시도를 모두 해제하면 "시도를 1개 이상 선택해주세요."를 표시하고 조회를 멈춘다. 조회 중에는 "데이터 조회 중..."을 표시한다. 조건에 맞는 집계가 없으면 "조건에 맞는 데이터가 없습니다. 필터를 조정해보세요."를 표시한다.
- 두 빈 선택·빈 결과 안내는 경고(st.warning)로 표시한다. 집계 결과 자체가 비어 있으면 지도·범례·표를 그리지 않는다. 집계는 있지만 회전율을 계산할 단지만 없는 경우에는 아래의 빈 지도·표 규칙을 적용한다.

### 6. 지도·범례·랭킹 테이블

- 배경은 기존 V-World 설정을 사용한다. 기본지도·위성지도·하이브리드를 각각 해당 타일 한 개로 전환한다. 현재 예제와 맞추기 위해 하이브리드에 위성 타일을 별도로 겹치지 않는다. 지도 출처 표시는 "V-World"로 한다. API 키가 없으면 설정 방법을 안내하고 임의의 영문 지도로 대체하지 않는다.
- 마커는 테두리를 포함한 지름 36px의 원, 흰색 2px 테두리, 그림자 0 2px 6px rgba(0,0,0,0.3)으로 만든다. 원 안의 순위는 흰색 14px 굵은 글자로 가운데에 표시하고 글자 그림자는 1px 1px 2px rgba(0,0,0,0.5)로 한다. 아이콘 크기는 36×36px, 기준점은 (18, 18)이다. 선택된 상위 단지의 전체 위치가 보이도록 지도 범위를 맞추고 사방에 20px 여유를 둔다. 별도의 최대 줌 제한은 추가하지 않는다.
- 마커 색은 5년 미만 #66BB6A, 5~10년 #FFA726, 10~20년 #EF5350, 20~30년 #AB47BC, 30년 이상 #5C6BC0, 연식 정보 없음 #9E9E9E로 고정한다.
- 마커에 마우스를 올리면 13px 글자와 줄 높이 1.6의 툴팁을 보여준다. 순서는 굵은 단지명, 시도·시군구·읍면동, "건축년도: 0000년 (연식 구간)", 굵은 거래 건수를 포함한 "거래량: 000건", "세대수: 000", "회전율: 0.00%"다. 건수와 세대수는 천 단위 쉼표를 사용하고, 없는 세대수·회전율은 "정보 없음"으로 표시한다.
- 오른쪽 범례 제목은 "연식 구분"이며 5단계 제목 크기(#####)를 사용한다. 다섯 연식 구간은 20px 크기의 색상 점 문자와 Streamlit 기본 본문 크기의 이름을 한 문단씩 위 순서대로 표시한다. 아래에 작은 회색 캡션으로 "전체 000건 중 세대수 매칭 000건"을 표시한다. 여기서 건수는 필터·좌표·세대수 범위 적용 후 단지로 최종 합산하기 전의 지역·단지·건축연도·면적대·계약연도·도로명별 집계 행 수다. 매칭 건수는 세대수가 NULL이 아닌 행의 수다. 원본 거래 건수나 상위 N개 단지 수와 혼동하지 않는다.
- 지도 아래 "랭킹 테이블"에는 기본 인덱스를 숨기고 순위, 단지명, 시군구, 읍면동, 건축년도, 연식_구분, 거래량 순서로 표시한다. 상위 결과에 세대수가 있는 단지가 하나라도 있으면 세대수, 회전율 열을 뒤에 추가한다. 표는 본문 너비에 맞춘다. st.dataframe의 기본 숫자·결측값 표시를 사용하고 column_config로 별도 형식을 지정하지 않는다. 예를 들어 회전율 값 4.7은 표에서는 4.7로, 툴팁에서는 4.70%로 표시한다.
- 회전율 랭킹에 계산 가능한 단지가 없으면 빈 지도와 빈 표를 표시하되 오류가 나지 않게 한다.

### 7. 실행과 완료 확인

구현을 마치면 uv run streamlit run projects/part08_trade_map/dashboard/app.py로 직접 실행한다. 이미 사용 중인 포트가 있으면 다른 포트를 사용하고 접속 주소를 알려준다. 코드 작성이나 문법 검사만으로 완료했다고 하지 않는다.

다음을 실제 데이터로 확인하고 수행 여부와 결과를 보고한다.

- 첫 화면의 매매·거래량·50개·서울특별시 강남구·최신 수록 연도·면적 전체 선택.
- 서울 밖 시도 선택과 시도→시군구→읍면동 연동. 수록 자료가 서울뿐이면 그 제한을 명시한다.
- 매매·전세·월세 전환, 거래량·회전율 전환, 10개와 50개 선택.
- 이전·다음 연도, 기간 범위 모드, 면적대·평형대와 세대수 필터. 거래유형·기간 모드를 바꿔도 선택 연도가 유지되는지, 새 수록 범위를 벗어나면 경계값으로 제한되는지 확인한다.
