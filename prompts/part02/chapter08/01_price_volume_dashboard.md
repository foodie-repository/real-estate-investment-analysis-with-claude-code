## 가격·거래량 대시보드 프롬프트 전체 문안

```text
## 프로젝트: 아파트 가격·거래량 대시보드 만들기

### 먼저 할 일: 입력 데이터 확인

현재 작업 폴더의 파일과 데이터 저장소를 먼저 살펴본다. 이 프롬프트의 데이터 절에 적힌 각 자료를 이름이 아니라 내용과 출처를 기준으로 찾아 실제 저장 위치와 형식, 필요한 정보와 실제 항목의 대응 관계, 기간 범위와 건수를 표로 요약한다.

파일명, 테이블명과 항목명을 추측하지 않는다. 필요한 자료나 정보가 없거나 같은 역할의 후보가 여러 개면 구현을 시작하지 말고, 찾은 후보와 확인이 필요한 내용을 먼저 알려준다.

### 1. 목적

개별 아파트 단지의 가격 추이와 거래량을 하나의 화면에서 함께 분석하는 대시보드를 구축한다.

- 개별 실거래가를 점으로 표시하여 가격 분포를 확인

- 월별 대표가격을 선으로 표시하여 추세를 확인

- 두 가지 뷰를 전환하며 같은 데이터를 다른 관점에서 분석

- 가격과 거래량을 분리 배치하되 같은 시간축을 공유하여 시장의 온도를 읽음

### 2. 구현 환경

- 스트림릿 웹 서비스: 가격·거래량 인터랙티브 대시보드

- 데이터베이스: 덕DB (읽기 전용)

- 패키지 관리: uv

### 3. 구현 언어: Python 3.11 이상

### 4. 데이터

현재 작업 폴더에서 아파트 매매 실거래와 임대차 실거래를 이름이 아니라 내용과 출처를 기준으로 찾아 사용한다. 매매 자료에는 지역, 단지, 전용면적, 계약 시점, 거래가격, 층, 건축연도, 주소와 취소·해제 및 거래 방식 정보가 필요하다. 임대차 자료에는 지역, 단지, 전용면적, 계약 시점, 보증금, 월세, 층, 건축연도와 주소 정보가 필요하다. 필요한 자료나 정보가 없거나 후보가 여러 개면 구현 전에 알려준다.

### 5. 데이터 전처리

#### 1) 거래 필터링

- 직거래는 중개 거래와 조건이 다를 가능성이 있으므로 분석 계약상 기본 제외하되 필요하면 포함·제외 결과를 비교한다

- 계약이 취소되거나 해제된 매매 거래는 제외한다

- 임대차 기록에서는 전세만 사용하고 월세는 제외한다

#### 2) 추정평형 및 평형대 분류

- 추정평형: 전용면적 × 0.4의 소수점 이하를 버린 정수. 예: 전용면적 84㎡ → 33평

- 평형대 (7단계): 10평 미만, 10평대, 20평대, 30평대, 40평대, 50평대, 60평 이상

#### 3) 주소 파싱

- 지역 문자열(예: "서울특별시 강남구 압구정동")을 시도·시군구·읍면동으로 분리

- 세종특별자치시는 시군구에 '세종시'로 대체

#### 4) 가격 단위

- 매매가격은 원본 단위를 확인한 뒤 억 원으로 변환해 표시한다

- 전세 보증금도 원본 단위를 확인한 뒤 억 원으로 변환해 표시한다

### 6. 시각화

#### 뷰 1: 개별 실거래가 (산점도 + 거래량)

매매 가격 → 전세 가격 → 매매 거래량 → 전세 거래량 순서로 4행 분리 배치한다. X축(시간)은 모든 행이 공유한다.

- 가격 행: 개별 거래를 점으로 표시한다. 같은 달의 점들이 겹치지 않도록 가로로 조금 퍼뜨리고, 평형대별로 색상을 구분한다

- 거래량 행: 월별 거래 건수를 막대로 표시한다

- 거래유형 선택에 따라 매매만(2행), 전세만(2행), 또는 매매+전세(4행)로 자동 조정

#### 뷰 2: 월별 중위가 (선 그래프 + 거래량)

뷰 1과 동일한 행 분리 배치.

- 가격 행: 월별 중위가를 선으로 표시하고 매매와 전세를 색상으로 구분한다

- 거래량 행: 월별 거래 건수를 막대로 표시한다

#### 공통 사항

- 차트는 가로와 세로 공간을 충분히 사용해 네 영역이 읽기 쉽게 보이게 한다

- 마우스를 올리면 상세 정보 표시(뷰 1: 단지명, 계약 시점, 거래 가격, 전용면적, 추정평형, 층 / 뷰 2: 중위가격, 거래량, 해당 월)

- 범례 표시

### 7. 사용자 인터페이스 (사이드바)

#### 뷰 전환

- 메인 영역 상단에서 뷰를 전환한다: "개별 실거래가", "월별 중위가" (탭 또는 라디오 버튼)

#### 지역 선택 (계층적 필터)

- 시도: 하나만 선택하며 기본값은 서울특별시로 한다

- 시군구: 하나만 선택하고 시도에 따라 목록을 갱신하며 기본값은 강남구로 한다

- 읍면동: 여러 개를 선택할 수 있게 하고 시군구에 따라 목록을 갱신하며 기본값은 전체로 한다

- 단지: 여러 개를 선택할 수 있게 하고 읍면동에 따라 목록을 갱신하며 기본값은 전체로 한다

#### 거래유형 선택

- 매매+전세 함께 보기, 매매만, 전세만 (라디오 버튼, 기본값: 매매+전세)

#### 평형 필터

- 평형대: 10평 미만부터 60평 이상까지 여러 개를 선택할 수 있게 하고 처음에는 30평대가 보이게 한다

#### 기간 선택

- 시작 연도 ~ 종료 연도 범위 슬라이더 (데이터 존재 범위 내에서 선택)

- 기본값: 전체 기간

#### 기타

- 직거래 포함 여부: 체크박스 (기본: 미포함)

### 8. 메인 화면 추가 정보

차트 아래에 매매 기준 요약 정보를 표시한다. "전세만" 선택 시에는 요약 정보를 표시하지 않는다.

- 선택한 조건의 총 거래 건수

- 최근 거래가 (최근 3건)

- 기간 내 최고가 / 최저가

```

## 파일로 저장한 프롬프트 전달

```text
첨부한 가격·거래량 대시보드 요구사항을 모두 읽고, 구현 전에 입력 데이터 위치·필터·거래 제외 기준·차트 구성을 표로 보여줘
```
