# P01-C03-S03 공동주택 정보 수집

- 책 위치: 1부 3장 3.3
- 필요한 준비: 공공데이터포털 API 키와 공동주택 단지 식별정보 조회 서비스 활용 신청
- 관련 코드: [`src/collectors/공동주택.py`](../../../src/collectors/공동주택.py)

## 공동주택 정보 수집 기능 만들기

```text
공공데이터포털 API에서 전국 공동주택 단지 목록을 수집하여 수집 결과를 현재 프로젝트의 저장 방식에 맞게 보관하는 기능을 만든다.

PublicDataReader를 사용해 구현한다.

수집 대상

- 아파트 단지만 수집한다 (오피스텔, 연립 등은 제외)

- 주요 정보: 단지명, 도로명 주소, 세대수, 동 개수, 최고 층수, 건축연도

수집 방식

- 전국 17개 시도를 순서대로 수집

- 마스터 데이터이므로 재수집 시 기존 데이터를 전량 삭제하고 새로 저장한다

- 특정 시도에서 오류가 나면 건너뛰고 다음 시도를 계속 진행한다

- 진행 상황과 완료 후 수집/오류 건수를 출력한다
```

## 서울 시험 실행

```text
현재 작업 폴더에서 공공데이터포털의 공동주택 기본정보 수집 기능을 찾아 서울특별시만 대상으로 시험 실행해줘. 아파트만 남겼는지 확인하고, 기능을 찾지 못하거나 후보가 여러 개면 실행하지 말고 알려줘. 완료 후 수집 건수, 제외한 주택 유형, 오류 건수와 실제 저장 위치를 요약해줘.
```

## 전국 데이터 수집

```text
현재 작업 폴더에서 공공데이터포털의 공동주택 기본정보 수집 기능을 찾아 전국을 대상으로 실행해줘. 아파트만 남기고, 기능을 찾지 못하거나 후보가 여러 개면 실행하지 말고 알려줘. 완료 후 시도별 성공·실패, 전체 저장 건수와 실제 저장 위치를 요약해줘.
```

## 수집 결과 확인

```text
현재 작업 폴더에서 공공데이터포털에서 수집한 전국 공동주택 기본정보를 내용과 출처를 기준으로 찾아 전체 건수와 샘플을 보여줘. 아파트만 포함됐는지, 세대수 구간별·시도별 단지 수와 세대수 정보가 비어 있는 단지 수를 확인해줘. 자료를 찾지 못하거나 후보가 여러 개면 먼저 알려줘.
```
