# P01-C03-S05 경계지도 수집

- 책 위치: 1부 3장 3.5
- 필요한 준비: V-World API 키
- 관련 코드: [`src/collectors/경계지도.py`](../../../src/collectors/경계지도.py)

## V-World API 키를 `.env`에 저장하기

```text
.env 파일에 V-World API 키를 추가해줘. 키 이름은 VWORLD_API_KEY로 해줘.
```

## 시군구 경계지도 수집 기능 만들기

```text
V-World WFS API로 전국 시군구 행정구역 경계를 수집하여 수집한 시군구 경계 정보를 GeoJSON 형식으로 저장하는 기능을 만든다.

수집 대상

- V-World WFS API의 lt_c_adsigg_info 레이어 (시군구 행정구역)

- 좌표계: EPSG:4326 (WGS84)

- 출력 형식: GeoJSON

수집 방식

- 전체 데이터를 페이징 처리하여 빠짐없이 수집한다

- 수집한 시군구 경계를 하나의 GeoJSON 파일로 합쳐 저장한다

- 진행 상황과 최종 수집 건수를 출력한다
```

## 수집 기능 실행

```text
현재 작업 폴더에서 V-World WFS API의 시군구 행정경계 수집 기능을 찾아 실행해줘.

기능이 없으면 이 API의 행정경계 레이어를 EPSG:4326 좌표계로 수집해 GeoJSON으로 보관하는 기능을 먼저 만들어.

완료되면 실제 저장 위치와 수집한 지역 수를 알려줘.
```

## 수집 결과 확인

```text
현재 작업 폴더에서 V-World WFS API로 수집한 시군구 행정경계 GeoJSON을 내용과 출처를 기준으로 찾아 열어줘. 시군구 개수, 포함된 정보와 좌표계를 확인하고 실제 파일 위치를 알려줘.
```

## 지도에서 시각적으로 확인

```text
현재 작업 폴더에서 V-World WFS API로 수집한 시군구 행정경계 GeoJSON을 찾아 간단한 지도에 표시해줘. 파일을 찾지 못하거나 후보가 여러 개면 먼저 알려줘.
```
