## 실거래가 수집 기능 만들기

```text
공공데이터포털 API에서 아파트 매매와 임대차 실거래를 수집해 분석에 사용할 수 있게 덕DB에 보관한다. 새 저장 이름을 추측하지 말고, 완료 뒤 실제 저장 위치와 데이터 구성을 설명한다.

PublicDataReader의 현재 사용법을 확인해 아파트 실거래가를 가져오는 기능을 사용한다.

수집 대상

- 매매 기록: 거래가격, 전용면적, 계약 시점, 층, 건축연도, 단지명, 주소와 거래 특성

- 매수·매도자나 계약 해제 여부처럼 API가 제공하는 분석용 정보도 보존한다

- 임대차 기록: 보증금, 월세, 전용면적, 계약 시점, 층, 건축연도, 단지명과 주소

- 계약 기간, 신규·갱신 여부와 갱신요구권 사용 여부도 보존한다

- 각 임대차 기록을 전세와 월세로 구분할 수 있게 한다(월세가 0원이면 전세, 아니면 월세)

지역 정보 형식

- 원래 지역 문자열을 보존하면서 시도·시군구·읍면동 수준으로 분석할 수 있게 한다

- 예: "서울특별시 강남구 압구정동", "경기도 성남시 중원구 은행동"

수집 방식

- 전국 시군구 코드 목록을 불러와서 시군구별로 순회하며 수집

- 같은 연도를 다시 수집할 때는 기존 데이터를 삭제하고 새로 저장한다

- 특정 시군구에서 오류가 나면 건너뛰고 다음 시군구를 계속 진행한다
```

## 서울 시험 실행

```text
현재 작업 폴더에서 공공데이터포털의 아파트 매매·임대차 실거래 수집 기능을 찾아 2024년 서울특별시만 대상으로 시험 실행해줘. 기능을 찾지 못하거나 후보가 여러 개면 실행하지 말고 알려줘. 완료 후 요청 범위, 매매·임대차별 저장 건수, 오류가 난 지역과 실제 저장 위치를 요약해줘.
```

## 수집 결과 확인

```text
현재 작업 폴더에 저장된 아파트 매매 실거래 자료를 내용과 출처를 기준으로 찾아 전체 건수와 샘플 5건을 보여줘. 샘플에는 지역, 단지명, 거래가격, 계약 시점이 포함되어야 해. 실제 저장 위치와 사용한 정보도 함께 설명하고, 해당 자료를 찾지 못하거나 후보가 여러 개면 먼저 알려줘.
```

## 전국 데이터 수집

```text
현재 작업 폴더에서 공공데이터포털의 아파트 매매·임대차 실거래 수집 기능을 찾아 2024년 전국을 대상으로 실행해줘. 기능을 찾지 못하거나 후보가 여러 개면 실행하지 말고 알려줘. 완료 후 지역별 성공·실패, 매매·임대차별 저장 건수, 실제 저장 위치와 중복 방지 결과를 요약해줘.
```
