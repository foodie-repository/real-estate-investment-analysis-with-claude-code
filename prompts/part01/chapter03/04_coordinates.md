책의 해당 절에서 사용하는 요청을 원고 순서대로 모았습니다. 각 요청은 해당 설명과 준비를 확인한 뒤 필요한 단계에서 사용하세요. 비교용 짧은 요청과 후속 수정 요청을 모두 한꺼번에 실행하지 않습니다.

## 2. 좌표 변환 프롬프트 전달

- 책 위치: 3.4 좌표 데이터 수집

```text
카카오 로컬 API의 주소 검색으로 아파트 도로명 주소를 위도·경도 좌표로 변환하고 현재 프로젝트의 저장 방식에 맞게 보관하는 기능을 만든다.

**변환 대상**

- 현재 작업 폴더의 아파트 매매·임대차 실거래 자료에서 도로명 주소를 찾아 중복을 제거한 목록
- 도로명만 쓰지 말고 시도+시군구+도로명을 합친 키를 사용한다
- 예: 역삼로 307 → 서울특별시 강남구 역삼로 307
- 저장할 정보: 도로명 주소, 경도(x), 위도(y)

**수집 방식**

- 이미 좌표가 있는 주소는 건너뛰고 새로운 주소만 변환한다 (증분 수집)
- API 호출 간격을 조절하여 단시간 대량 호출로 인한 차단을 방지한다
- 진행 상황을 출력한다 (전체 주소 수 대비 현재 진행률)
- 완료 후 성공 건수와 실패 건수를 출력한다
```

## 3. 실행 명령어

- 책 위치: 3.4 좌표 데이터 수집

앞선 대화와 자료를 이어서 사용하는 요청입니다. 책의 사례 시점·조건과 자신의 자료를 확인하세요.

```text
현재 작업 폴더의 서울특별시 아파트 매매·임대차 실거래에서 중복을 제거한 도로명 주소를 찾아, 카카오 지오코딩 API로 위도·경도를 수집하는 기능을 시험 실행해줘. 이미 좌표가 있는 주소는 다시 요청하지 마. 필요한 자료나 기능을 찾지 못하면 실행하지 말고 알려주고, 완료 후 대상·성공·실패 건수와 실제 저장 위치를 요약해줘.
```
