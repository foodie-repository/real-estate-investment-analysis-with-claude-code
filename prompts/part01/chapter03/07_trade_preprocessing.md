# P01-C03-S07 아파트 실거래가 데이터 전처리

- 책 위치: 1부 3장 3.7
- 필요한 준비: 매매·임대차 실거래, 주소별 위도·경도, 공동주택 기본정보
- 관련 코드: [`src/preprocessing/trade.py`](../../../src/preprocessing/trade.py)

## 공통 데이터 정리 기능 만들기

```text
현재 작업 폴더에서 다음 네 자료를 이름이 아니라 내용과 출처를 기준으로 찾는다: 아파트 매매 실거래, 임대차 실거래, 카카오 지오코딩으로 만든 주소별 위도·경도, 공공데이터포털의 공동주택 기본정보. 실제 저장 위치와 사용할 정보를 요약한 뒤, 원본을 바꾸지 않고 후속 분석에서 재사용할 수 있는 공통 데이터 정리 기능을 만든다. 자료가 없거나 후보가 여러 개면 구현 전에 알려준다.

만든 공통 데이터 정리 기능은 관심단지 시세 추적, 투자 수익률 계산, 지역별 지표 시각화, 거래량 지도와 가격·거래량 분석에서 필요한 항목만 골라 재사용할 수 있게 한다.

완료 조건

- 수집한 원본 데이터는 수정하지 않고 분석 결과를 만들 때만 가공한다

- 아래 정리 항목은 프로젝트에 필요한 것만 선택해 적용할 수 있게 한다

전처리 항목

1)  주소 파싱

2)  - 지역 문자열(예: "서울특별시 강남구 대치동")을 시도·시군구·읍면동으로 분리

3)  - 세종특별자치시는 시군구에 '세종시'로 대체

4)  전용면적 분류 (실무 관용 5단계)

5)  - 초소형: 40㎡ 이하 / 소형: 40㎡ 초과~60㎡ 이하 / 중소형: 60㎡ 초과~85㎡ 이하

6)  - 중대형: 85㎡ 초과~135㎡ 이하 / 대형: 135㎡ 초과

7)  추정평형 및 평형대 분류

8)  - 추정평형 = 전용면적(㎡) × 0.4 (소수점 반올림)

9)  - 평형대: 10평 미만, 10평대, 20평대, 30평대, 40평대, 50평대, 60평 이상

10) 연식 계산

11) - 연식 = 현재 연도 - 건축연도 (최소 1년)

12) - 연식 구분: 5년 미만, 5년 이상~10년 미만, 10년 이상~20년 미만, 20년 이상~30년 미만, 30년 이상

13) 좌표 매칭

14) - 실거래 기록의 주소와 카카오 지오코딩으로 만든 주소별 위도·경도 자료를 연결

15) 세대수 매칭

16) - 공동주택 기본정보와 실거래 기록을 지역·단지 기준으로 안전하게 연결

17) - 회전율 = 거래량 / 세대수 × 100
```

## 전처리 결과 검증

```text
현재 작업 폴더에서 매매·임대차 실거래를 분석용으로 정리하는 공통 기능을 찾아 매매 실거래에 적용해줘. 기능을 찾지 못하면 이름을 추측하지 말고 알려줘.

전체 건수, 지역 분리 결과, 면적 분류와 추정 평형 결과를 보여주고,

주소별 좌표와 공동주택 기본정보가 연결된 비율도 각각 보여줘.
```
