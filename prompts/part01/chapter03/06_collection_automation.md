# P01-C03-S06 데이터 자동 수집

- 책 위치: 1부 3장 3.6
- 필요한 준비: 3.1~3.5절의 수집 기능

## 자동 수집 기능 만들기

```text
현재 작업 폴더를 조사하여 다음 다섯 기능이 실제로 있는지 확인하고, 존재하는 실행 방법을 사용해 자동 수집으로 묶어줘: ① 공공데이터포털의 아파트 매매·임대차 실거래 수집, ② KB부동산의 매매가격지수·전세가격지수·전세가율 수집, ③ 공공데이터포털의 전국 공동주택 기본정보 수집, ④ 실거래 도로명 주소를 카카오 지오코딩 API로 위도·경도로 변환, ⑤ V-World WFS API의 시군구 행정경계를 GeoJSON으로 수집. 없는 기능이나 실행 방법이 불명확한 기능이 있으면 자동화를 만들기 전에 목록과 확인할 내용을 알려줘.

매일 실행할 작업과 매월 실행할 작업으로 나누고 현재 운영체제에 맞는 방식을 사용한다.

매일 실행할 작업:

- 실거래가 (매매 + 전월세)

매월 실행할 작업:

- KB 통계 → 공동주택 기본정보 → 주소별 좌표 → 경계지도 순서

- 경계지도는 1월에만 실행하도록 월 체크 조건 추가

공통 요건

- 각 단계의 시작/완료 시간을 기록한다

- 오류가 나도 다음 단계는 계속 진행한다

- 실행 기록을 날짜별로 남겨 나중에 성공·실패를 확인할 수 있게 한다

- 매일 수집할 때 대상 연도를 빠뜨리지 않게 한다
```

## 자동화 시험 실행

```text
현재 작업 폴더에서 아파트 매매·임대차 실거래를 갱신하는 매일 자동화와, KB부동산 세 지표·공동주택 기본정보·주소별 좌표·시군구 행정경계를 갱신하는 매월 자동화를 찾아 각각 시험 실행해줘. 단계별 성공·실패, 실행 시간과 실제 실행 기록 위치를 요약하고, 해당 자동화를 찾지 못하면 먼저 알려줘.
```

## macOS 크론탭 등록

```text
macOS 크론탭에 자동 수집을 등록해줘.

- 매일 오전 3시: 공공데이터포털의 아파트 매매·임대차 실거래를 갱신하는 자동화 실행

- 매월 1일 오전 4시: KB부동산 세 지표, 전국 공동주택 기본정보, 주소별 위도·경도와 시군구 행정경계를 차례로 갱신하는 자동화 실행

- 현재 프로젝트의 실제 위치와 실행 방법을 먼저 확인해 일정에 반영해줘.
```

