# P01-C03-S02 KB부동산 통계 데이터 수집

- 책 위치: 1부 3장 3.2
- 필요한 준비: 3.1절 실거래가 수집 환경
- 관련 코드: [`src/collectors/KB통계.py`](../../../src/collectors/KB통계.py)

## KB부동산 통계 수집 기능 만들기

```text
KB부동산 통계 수집 기능을 만든다.

PublicDataReader의 현재 사용법을 확인해 KB부동산 공개 통계를 가져온다. API 키는 필요 없다.

수집 지표 (3종)

- 매매가격지수

- 전세가격지수

- 전세가율

데이터 범위

- 시도 수준 및 시군구 수준 모두 포함

- 제공되는 전체 기간 수집

저장 방식

- 세 지표를 서로 구분해 이후 개별적으로 조회할 수 있게 저장한다

- 재수집 시 기존 데이터를 삭제하고 새로 저장한다

- 진행 상황과 저장 건수를 출력한다
```

## 수집 기능 실행

```text
현재 작업 폴더에서 KB부동산의 아파트 매매가격지수·전세가격지수·전세가율 수집 기능을 찾아 제공되는 전체 지역과 기간으로 실행해줘. 기능을 찾지 못하거나 후보가 여러 개면 실행하지 말고 알려줘. 완료 후 세 자료의 기간, 지역 수준, 저장 건수와 실제 저장 위치를 요약해줘.
```

## 수집 결과 확인

```text
현재 작업 폴더에서 KB부동산의 아파트 매매가격지수, 전세가격지수와 전세가율 자료를 내용과 출처를 기준으로 각각 찾아 건수를 확인해줘.

서울의 최근 매매가격지수 5개월치를 보여줘. 세 자료의 실제 저장 위치와 사용한 정보도 설명하고, 찾지 못한 자료가 있으면 이름을 추측하지 말고 알려줘.
```
