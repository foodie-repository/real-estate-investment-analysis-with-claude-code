# P01-C02-S09 클로드 코드와 효과적으로 협업하는 법

- 책 위치: 1부 2장 2.9
- 사용 순서: 리서치 → 계획 → 구현

## 모호한 요청의 예

```text
아파트 가격이랑 거래량 보는 대시보드 만들어줘.
```

## 1단계 리서치

```text
현재 프로젝트 전체를 먼저 살펴 실제 데이터 종류와 저장 위치, 주요 정보, 이미 만든 기능과 실행 방법을 요약해줘. 이름을 추측하거나 새 구조를 만들지 말고, 찾지 못한 정보는 없다고 알려줘.
```

## 2단계 계획

```text
/plan 현재 작업 폴더의 파일, 데이터 저장소와 실행 가능한 기능을 조사한 뒤 아파트 가격·거래량 대시보드 구현 계획을 작성해줘. 사용할 실제 데이터와 필요한 정보, 화면 구성, 검증 방법을 포함하고 아직 구현하지 마.
```

계획을 검토할 때 사용할 수 있는 수정 요청 예시입니다.

```text
가격·거래량 대시보드에는 [사용할 자료의 출처와 필요한 정보]를 써야 해. 계획에 적힌 [잘못 선택한 자료]는 사용하지 마.
```

```text
이 기능은 지금 필요 없어
```

```text
차트는 플롯리 대신 알테어로 해줘
```

```text
거래량은 월별로 집계해야 해
```

## 3단계 구현

```text
이 대화와 현재 작업 폴더에서 내가 승인한 아파트 가격·거래량 대시보드 구현 계획을 찾아 핵심 요구사항을 먼저 요약해줘. 계획이 하나로 명확하면 그대로 구현하고 직접 실행해 검증해줘. 계획을 찾지 못하거나 여러 계획이 충돌하면 구현하지 말고 확인이 필요한 내용을 알려줘.
```
