# 2.5 바이브 코딩 첫 경험

책의 해당 절에서 사용하는 요청을 원고 순서대로 모았습니다. 각 요청은 해당 설명과 준비를 확인한 뒤 필요한 단계에서 사용하세요. 비교용 짧은 요청과 후속 수정 요청을 모두 한꺼번에 실행하지 않습니다.

## 1. 첫 번째 실습: 구구단 프로그램 생성

- 책 위치: 2.5 바이브 코딩 첫 경험

```text
구구단 2단부터 9단까지 출력하는 파이썬 프로그램을 만들어줘.
```

## 2. 첫 번째 실습: 구구단 프로그램 생성

- 책 위치: 2.5 바이브 코딩 첫 경험

```text
현재 작업 폴더에서 구구단 2단부터 9단까지 출력하는 연습용 파이썬 프로그램을 찾아 실행해줘.
```

## 3. 수정 요청

- 책 위치: 2.5 바이브 코딩 첫 경험

```text
각 단을 가로로 한 줄에 출력해줘. 예를 들어 "2 x 1 = 2, 2 x 2 = 4, ..." 형태로.
```

## 4. 두 번째 실습: 대화로 연습 파일 삭제

- 책 위치: 2.5 바이브 코딩 첫 경험

```text
현재 작업 폴더에서 구구단 2단부터 9단까지 출력하는 연습용 파이썬 파일을 찾아 삭제해줘. 후보가 여러 개라면 삭제하기 전에 목록을 보여줘.
```

## 6. 구체적인 요청

- 책 위치: 2.5 바이브 코딩 첫 경험

