# P01-C02-S05 바이브 코딩 첫 경험

- 책 위치: 1부 2장 2.5
- 사용 시점: 클로드 코드로 첫 파이썬 프로그램을 만들 때

## 구구단 프로그램 만들기

```text
구구단 2단부터 9단까지 출력하는 파이썬 프로그램을 만들어줘.
```

## 프로그램 실행하기

```text
현재 작업 폴더에서 구구단 2단부터 9단까지 출력하는 연습용 파이썬 프로그램을 찾아 실행해줘.
```

## 출력 형태 수정하기

```text
각 단을 가로로 한 줄에 출력해줘. 예를 들어 "2 x 1 = 2, 2 x 2 = 4, ..." 형태로.
```

## 연습 파일 삭제하기

```text
현재 작업 폴더에서 구구단 2단부터 9단까지 출력하는 연습용 파이썬 파일을 찾아 삭제해줘. 후보가 여러 개라면 삭제하기 전에 목록을 보여줘.
```

## 모호한 요청과 구체적인 요청 비교

모호한 요청:

```text
뭔가 만들어줘
```

구체적인 요청:

```text
구구단 2단부터 9단까지 출력하는 파이썬 프로그램을 만들어줘.

각 단은 가로로 한 줄에 출력하고, 단 사이에 빈 줄을 넣어줘.
```
