# 부록. 책의 프롬프트를 바꾸어 나만의 대시보드 만들기 — 프롬프트

9장 문안을 바탕으로 월세 비중 대시보드를 만드는 사용자 요청 6개입니다. 앞선 대화에서 확인한 자료와 결정 사항을 이어서 사용합니다. 책의 사례 시점·조건을 자신의 자료와 대조하고, AI의 질문에 맞춰 답변을 조정하세요.

먼저 9장 9.2절의 [가격·거래량 대시보드 프롬프트 전체 문안](../part02/chapter09/01_price_volume_dashboard.md)을 `prompt_ch09_price_volume.md`로 저장하고 첫 요청에 첨부합니다. 9장까지의 실습과 임대차 자료 수집이 준비되어 있어야 합니다. AI 답변과 대시보드 완성 코드는 이 파일에 포함하지 않습니다.

## 1. 첫 요청: 알고 싶은 것, 하지 않을 것, 물어볼 방법

- 책 위치: 책의 문안에서 가져올 것, 바꿀 것, 뺄 것

앞선 대화와 자료를 이어서 사용하는 요청입니다. 파일·폴더 이름과 지역·단지·면적·기간을 자신의 프로젝트에 맞게 확인하세요.

```text
@prompt_ch09_price_volume.md 는 책의 9장 가격·거래량 대시보드 전체 문안이야. 지금 그대로 구현하라는 뜻은 아니야. 나는 송파구 잠실동 리센츠 30평대에서 신고된 임대차 계약 중 월세 비중이 월별로 어떻게 달라졌는지 보고 싶어. 기존 프로젝트와 실제 자료를 확인하고, 이 문안에서 가져올 조건과 바꿀 조건, 뺄 조건을 정리해줘. 계산 기준은 작은 예로 설명해줘. 내가 정해야 할 것은 선택지를 고를 수 있는 질문 창(AskUserQuestion)으로 한 번에 네 가지 이내로 물어봐줘. 선택지마다 실제 자료로 계산한 결과와 네 추천을 함께 보여줘. 내가 미처 생각하지 못했을 판단 거리도 찾아서 같이 물어봐줘. 예를 들어 최근 자료, 값이 비어 있는 경우, 거래가 없는 경우처럼. 답을 받은 뒤 요구사항을 한 장으로 정리해줘. 첫 버전은 월별 전세·월세 건수와 월세 비중만 보여줘. 신규·갱신 비중, 보증금이나 월세 가격, 지도, 7장 연결, 투자 판단 표시는 넣지 마. 아직 구현하거나 기존 앱과 원자료를 바꾸지 마.
```

## 2. 요구사항 점검도 AI에게 맡긴다

- 책 위치: AI와 대화해 요구사항을 한 장으로 정리한다

앞선 대화와 자료를 이어서 사용하는 요청입니다. 파일·폴더 이름과 지역·단지·면적·기간을 자신의 프로젝트에 맞게 확인하세요.

```text
방금 정리한 요구사항을 아래 질문으로 점검해서 표로 보여줘. 질문마다 어디서 정했는지(첫 요청, 질문 창, 네가 혼자 정함, 아직 정하지 않음)와 요구사항에 적힌 내용을 적고, 빠진 것은 ‘빠짐’으로 표시해줘. 아직 고치지는 마.

1. 대상과 기간: 어떤 대상(지역·단지·면적)을 어느 기간으로 보는가?
2. 셀 계약: 어떤 거래나 계약을 세는가?
3. 똑같은 행: 모든 항목이 같은 행은 어떻게 세는가?
4. 분모: 비율은 무엇으로 나누는가?
5. 구분이 빈 행: 구분값이 비었거나 다른 값이면 어떻게 하는가?
6. 적은 달과 빈 달: 거래가 없는 달과 건수가 적은 달은 어떻게 보이는가?
7. 결과물: 어디에, 무엇으로 만드는가?
8. 하지 않을 것: 첫 요청에서 뺀 기능이 모두 빠졌는가?
9. 완료 기준: 무엇과 대조해서 완료를 판단하는가? 지금 자료에 없는 경우는 어떻게 시험하는가?
```

## 6. 응용 과제: 비교 단지 추가하기

- 책 위치: 최종 문안을 저장하고 다른 질문으로 넓힌다

앞선 대화와 자료를 이어서 사용하는 요청입니다. 파일·폴더 이름과 지역·단지·면적·기간을 자신의 프로젝트에 맞게 확인하세요.

```text
이번에는 같은 잠실동의 잠실포스코더샵 30평대를 비교 단지로 추가하고 싶어.

**유지할 것:** 계약년월 기간(2022-01~2025-12)과 '자료 종료' 표시, 계산 기준(신고된 계약 전체, 완전히 같은 행도 그대로 세기, 구분 불명은 비중에서 제외), '표본 적음' 기준(10건 미만), 넣지 않을 것 목록.

**바꿀 것:**

- 대상을 리센츠 84.99㎡와 잠실포스코더샵 30평대 두 단지로 늘려줘.
- 포스코더샵은 30평대 면적이 여러 개일 수 있으니 실제 면적과 건수를 확인해서 알려주고 합쳐서 하나의 계열로 봐줘.
- 두 단지의 비중을 하나로 합치지 말고 단지별로 따로 보여줘.

**확인할 것:** 포스코더샵은 거래가 적을 거야. 0%나 100%가 나온 달이 실제로 몇 건으로 만들어졌는지, 거래가 없는 달은 비어 있는지 화면에서 바로 볼 수 있게 해주고, 원자료 SQL과 단지별로 대조해줘.

결정이 필요한 게 있으면 구현 전에 물어봐 주고, 없으면 바로 구현해서 검증 결과를 보고해줘. 검증이 끝나면 띄운 서버는 종료하고, 이 변경까지 반영한 최종 문안을 final_prompt_rent_share_compare.md로 따로 저장해줘.
```
