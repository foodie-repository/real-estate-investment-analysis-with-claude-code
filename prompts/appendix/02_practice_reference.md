# 부록. 실습에 다시 쓰는 참고 자료 — 프롬프트

책의 해당 절에서 사용하는 요청을 원고 순서대로 모았습니다. 각 요청은 해당 설명과 준비를 확인한 뒤 필요한 단계에서 사용하세요. 비교용 짧은 요청과 후속 수정 요청을 모두 한꺼번에 실행하지 않습니다.

## 1. 오랜만에 프로젝트를 다시 열었을 때

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
이 프로젝트에서 만든 부동산 분석 도구를 찾아 각각 무엇을 하는지와 실행 방법을 알려줘. 저장된 자료의 지역·기간도 확인해줘. 확인할 수 없는 항목은 따로 적고, 아직 파일 수정이나 자료 수집은 하지 마.
```

## 2. 관심단지 시트를 갱신하기 전에 확인할 때 — 4장

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
관심단지 목록과 선택한 면적을 보여주고, 저장된 자료로 계산할 기준월과 자료의 최신월을 확인해줘. 매매와 신규 전세 중 한쪽이 없거나 거래 건수가 적은 단지는 따로 알려줘. 아직 구글 시트에는 쓰지 마.
```

## 3. 매수 시점을 바꿔 비교할 때 — 5장

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
(단지·면적)의 매수 시점을 (연월)로 두고 (비교 시점들)의 수익률을 저장된 자료로 계산해줘. 각 시점에 실제로 사용한 가격과 거래 건수, 초기 갭을 함께 보여줘. 계산할 수 없는 구간은 비워두고 이유를 적어줘. 기존 계산 규칙은 바꾸지 마.
```

## 4. 지역 지표의 변화가 눈에 띌 때 — 6장

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
저장된 자료에서 (지역)의 (기간) 매매·전세 지수와 전년 동월 대비 값을 함께 확인해줘. 최근의 움직임과 작년 같은 달의 영향으로 나누어 설명하고, 숫자로 확인한 내용과 추가로 조사할 해석을 구분해줘.
```

## 5. 가격·갭 비교 조건을 맞출 때 — 7장

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
(비교할 단지들)을 (기간·면적·층 조건)으로 비교해줘. 매매와 전세의 대표가격, 각각의 거래 건수, 갭과 전세가율을 함께 보여줘. 신규·갱신과 직거래의 포함 기준도 알려주고, 같은 조건으로 비교할 수 없는 단지는 따로 표시해줘. 원자료와 계산 규칙은 고치지 마.
```

## 6. 지도에서 단지가 빠졌을 때 — 8장

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
(단지)가 거래량 지도에 없는 이유를 확인해줘. 원자료에 거래가 있는지, 선택한 조건에서 제외됐는지, 주소와 좌표 연결에 실패했는지 나눠서 살펴봐줘. 회전율을 볼 때는 세대수 연결 여부도 확인해줘. 확인하지 못한 원인은 추측으로 표시하고, 아직 자료나 코드는 고치지 마.
```

## 7. 가격선이 크게 움직인 달을 확인할 때 — 9장

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text
(단지·면적)의 (연월)에 월별 중위가가 크게 움직인 이유를 저장된 개별 거래와 대조해줘. 거래 건수와 층·면적 구성을 앞뒤 달과 비교하고, 가격 변화와 거래 구성 변화 중 확인할 수 있는 내용을 구분해줘. 자료만으로 알 수 없는 원인은 단정하지 마.
```

## 8. 오류가 나거나 기대한 화면이 나오지 않을 때

- 책 위치: 2. 장별 프롬프트 찾아보기와 후속 요청

```text

```
