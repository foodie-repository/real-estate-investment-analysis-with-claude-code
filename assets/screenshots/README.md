## 자료와 재사용 기준

- 4·5장도 원고의 시트 이미지를 그대로 사용했습니다. 4장 이미지는 당시의 최근 거래가 표시 방식이며, 현재 참고 코드는 동일 기준월의 중앙값을 사용합니다. 5장 이미지의 공란은 매수 시점 거래가 조회되지 않은 경우입니다. 화면의 업데이트 표시는 모든 자료가 그 날짜까지 수집되었다는 뜻이 아닙니다.

- 6장의 가격지수·전세가율은 KB부동산 자료를 사용하며, 매매 거래량은 실거래 자료를 집계합니다. 7~9장은 수집한 실거래 자료와 해당 장에서 설명하는 단지·좌표 자료를 사용한 화면입니다.
- 9장은 원고에 2026년 9월 27일 연결 실습 화면으로 기록되어 있습니다. 7장의 2026년 6~8월 비교에서 선택한 대상을 연결하되, 9장에서는 장기 이력을 별도로 조회합니다. 전세에는 신규·갱신 계약이 모두 포함됩니다.
- 원고의 PNG 파일을 크기·내용 변경 없이 복사했습니다. 지도 제공자 표기도 원본대로 유지했습니다. 화면의 수치를 수정하거나 새로 생성하지 않았습니다.
- 원고 이미지의 UI와 현재 공개 코드에는 표시 방식의 차이가 있을 수 있습니다. 6장 이미지의 배경지도는 CartoDB이며, 현재 코드의 지도 배경 설정은 V-World입니다.
- 이번 교체는 기존 원고 이미지의 재사용이며, 데이터 재수집이나 최신 데이터 재실행을 의미하지 않습니다. 원본 데이터베이스와 API 키는 포함하지 않습니다. 코드 실행 검증은 [검증 기록](../../VALIDATION.md)에서 별도로 확인할 수 있습니다.

## 책 미리보기 웹 화면

[책 미리보기 이미지](book-preview-reading-guide-595c0c66.png)는 2026-10-31에 [공개 미리보기의 「이 책을 읽는 방법」](https://foodie-repository.github.io/real-estate-investment-analysis-with-claude-code/#reading-guide) 첫 두 쪽을 캡처한 화면입니다. 왼쪽 목차, 본문, 책에 수록된 도구의 그림, 페이지 넘김 버튼을 함께 보여줍니다. 루트 README에서는 이미지 전체를 누르면 책 미리보기로 이동합니다.

1440×1000 화면을 2배 해상도인 2880×2000 PNG로 저장했습니다. 웹 화면을 그대로 캡처했으며 본문과 수치, 이미지를 따로 수정하지 않았습니다. 캡처 당시 본문 글자 크기는 18이며, 표시된 페이지 수는 기기와 글자 크기에 따라 달라집니다. 화면 안의 시트 이미지는 위에 설명한 원고 수록 예시로, 실시간 데이터 화면이 아닙니다.
