## 자료와 재사용 기준

- 6장의 가격지수·전세가율은 KB부동산 자료를 사용하며, 매매 거래량은 실거래 자료를 집계합니다. 7~9장은 수집한 실거래 자료와 해당 장에서 설명하는 단지·좌표 자료를 사용한 화면입니다.
- 9장은 원고에 2026년 9월 27일 연결 실습 화면으로 기록되어 있습니다. 7장의 2026년 6~8월 비교에서 선택한 대상을 연결하되, 9장에서는 장기 이력을 별도로 조회합니다. 전세에는 신규·갱신 계약이 모두 포함됩니다.
- 원고의 PNG 파일을 크기·내용 변경 없이 복사했습니다. 지도 제공자 표기도 원본대로 유지했습니다. 화면의 수치를 수정하거나 새로 생성하지 않았습니다.
- 원고 이미지의 UI와 현재 공개 코드에는 표시 방식의 차이가 있을 수 있습니다. 6장 이미지의 배경지도는 CartoDB이며, 현재 코드의 지도 배경 설정은 V-World입니다.
- 이번 교체는 기존 원고 이미지의 재사용이며, 데이터 재수집이나 최신 데이터 재실행을 의미하지 않습니다. 원본 데이터베이스와 API 키는 포함하지 않습니다. 코드 실행 검증은 [검증 기록](../../VALIDATION.md)에서 별도로 확인할 수 있습니다.
