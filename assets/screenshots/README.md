## 데이터와 표시 범위

- `tests/sample_data.py`의 가상 검증 자료로 실행했습니다. 단지명은 `검증단지1`~`검증단지3`이며, 가격·거래량·KB 지수와 좌표는 실제 시장 자료가 아닙니다. 표시된 지역명과 기간도 예시 조건입니다.
- 6장은 시계열 분석, 7장은 비교표, 9장은 개별 실거래가와 거래량 화면입니다. 7장은 표 상단을 발췌했으므로 모든 컬럼과 하단 조작부가 보이지 않습니다.
- 8장은 지도 아래의 거래량·회전율 순위표만 발췌했습니다. 촬영 시 외부 지도 타일은 요청하지 않았으며, 지도 배경의 표시 상태를 보여주는 이미지는 아닙니다.
- 이미지는 실제 앱을 브라우저에서 실행해 캡처했습니다. 앱의 수치와 차트는 수정하지 않았습니다. 2배 배율의 PNG로 저장했으며, README에서는 가로폭에 맞춰 축소됩니다. 큰 이미지를 열면 원래 해상도로 볼 수 있습니다.
- 실제 데이터 수집이나 외부 서비스 연결의 검증 범위는 [검증 기록](../../VALIDATION.md)을 확인하세요.
